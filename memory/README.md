# AI 助手记忆文件

本目录存放开发本仓库过程中 AI 助手（Trae）沉淀的记忆文件，记录了项目的硬约束、工程约定、踩坑经验与阶段性话题。

> 这些文件是开发过程的「经验沉淀」，并非项目运行所必需。读者可据此理解关键设计决策的来龙去脉，以及避开已踩过的坑。

## 文件说明

| 文件 | 作用域 | 内容 |
|------|--------|------|
| `user-profile.md` | 跨项目 | 用户偏好与通用技术栈（沟通语言、开发方式等） |
| `project-memory.md` | 当前项目 | 硬约束、工程约定、踩坑经验（Lessons Learned） |
| `topics.md` | 时间线 | 按会话维度记录的阶段性话题摘要 |

## 安全说明

- 所有真实密钥（如 DeepSeek API Key）均已脱敏，仅以环境变量名 `DEEPSEEK_API_KEY` 出现。
- 运行项目前请通过环境变量注入真实 Key，切勿回填到本目录文件中。
