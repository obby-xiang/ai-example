# 决策看板（决策流水）

> 用途：决策流水（谁在何时定了什么、定到什么程度；含裁决中的待定项）；🏛️ 类为立法性/纪律性裁决，长期有效、不随批次过期。
> 数据截止：**2026-10-12 18:40**（`date` 实测）；来源 = `docs/adr/DECISION-REGISTER.md`（DC-01~DC-22）+ 各批决策卡 + 入库留痕；分组日 = 裁决/签署日，组内倒序。
> 图例：✅ 已定稿并执行完毕 ｜ 🔧 执行中（部分面已入库）｜ 📌 已定稿待施工 ｜ 🔍 会审中 ｜ 📝 草案 ｜ 🏛️ 立法性纪律（长期有效）｜ ⏸️ 暂缓。
> 行级口径：DC-01→DC-22 与各批裁决**逐条单列、零合并**；「结论」= 自足一句话（≤45 字）；「依据」= 登记表 anchor / `docs/evidence/` 补档件 / 仓外卡件名 / commit 短哈希。
> 决策口径：批次级裁决**必过三方会审**（草案 → 两方互不见结论并行评议 → 汇总定稿）；签字节点常态由 K3 代行，**业务裁决与对外授权仍归用户**。
