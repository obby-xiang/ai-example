## T2a 包：纯前端唯一投影化

### 卡 T2a-D#1 双投影分离与广播域
- 选项：(a) toolRun/pendingCall 合并单 status 域 (b) 双投影分离，帧广播只作用 pendingCall 投影 (c) 广播同写两投影
- 选择：(b)
- 理由：两投影由不同帧写入、域不同（types/ai.ts:161 vs :213）；红队 C1 实证合并广播会把已 succeeded 的 toolRun 误覆为 cancelled
- 守卫（随卡生效）：广播仅覆盖 status=='pending' 的 pendingCall；目标 toolRun 已终态不改写；localTerminal 集合补 succeeded
- 被否方案的坑：(a)=大规模重构且丢语义；(c)=C1 点名的误伤路径
- 推翻条件：实测出现双投影读侧口径冲突新证据
- 验证用例：GFd 双卡场景冒烟——同 toolCallId 一条 succeeded 一条 pending 时，取消帧只收敛 pending 那条

### 卡 T2a-D#2 cancelled 终态与终态单调
- 选项：(a) 本地 cancel 直接落终态 (b) 本地 cancel 乐观置位、服务端帧 status 为最终裁决（终态单调，已终态不降级）
- 选择：(b)（红队 A2：POST 与 SSE 双通道无序，必须写死 winner；后端权威原则）
- 状态映射表（随卡）：FRONTEND_RESULT→succeeded / FRONTEND_CANCELLED→cancelled / TIMEOUT→expired / REJECTED→rejected / BLOCKED→blocked；types/sse.ts PendingStatus 联合补 FRONTEND_CANCELLED（C2）
- 镜像兼容：旧镜像非 pending 残留按终态展示、不进 pending 扫描（C2）
- 附带修复：pendingToolCall getter 改为跳过非 pending 继续向前扫（C3）；帧到达且本地 activeForm 仍 filling 时提示"该表单已在其他窗口提交"（B2 缓释）
- 被否方案的坑：(a) 他端先提交时卡片"已取消→已成功"翻闪，违背后端权威
- 推翻条件：后端帧 status 被证不可信
- 验证用例：他端提交+本地取消竞态冒烟，终态恒 succeeded 无翻闪

## T2b 包：刷新续填（端点语义先定后施工）

### 卡 T2b-D#1 session→run 索引
- 选项：(a) 复用会话锁值 (b) 新 Redis 键 ai:session:current:<sessionId> (c) 全量扫 allRunIds
- 选择：(b)：挂起时写 runId、轮终态清除、TTL 与锁 watchdog 对齐、O(1)
- 被否坑：(a) 锁仅活轮存活，超时/他端提交/进程死三场景全返回 null（红队 B1 实证）；(c) O(全部 runId) 且无 TTL 语义
- 推翻条件：实测锁值在三场景可存活（与 B1 证据相反）
- 验证用例：后端单测——挂起后读键得 runId；终态后读键为 null

### 卡 T2b-D#2 runs/current 端点语义
- 返回结构化状态：{runId, snapshotStatus, pendingEntries[{toolCallId, entryStatus}], unresolvedExternal}；终态判定对齐 ResumeService unresolvedExternal 口径（消 D1 中间态误判）
- 三分支降级口径：已超时→条目 TIMEOUT、前端标 expired；他端已提交→条目 FRONTEND_RESULT、按终态展示；进程已死→索引键缺失、回退历史渲染+挂起卡标 expired。任何分支不留 pending 残留
- 约束声明：不承诺同 session 多页签共享（B2 文档化）
- 验证用例：三分支各一后端断言 + 各一 CDP 冒烟

### 卡 T2b-D#3 前端重建路线：快照重建+增量续收（无全量回放）
- 选项：(a) reattach 全量回放重建 (b) 快照重建+增量续收
- 选择：(b)：loadHistory 先行完成（historyLoaded 前不触发重建）；挂起卡由 pendingEntries 快照经唯一投影 upsert 就地重建，不 append 新消息；续收以 lastSeq=归档最大 seq 挂 SSE，只收新帧
- 被否坑：(a)=红队 A1/A3/B3：双重渲染、孤儿过滤失效、死卡复活
- 推翻条件：快照字段不足以重建挂起卡（施工时证伪则升级裁决）
- 验证用例：挂起中刷新——单卡、无重复工具卡、新帧正常续收
