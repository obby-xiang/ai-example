# 接口文档（REST + SSE）

- 基址：`http://127.0.0.1:18080`
- 统一响应：`{ "code": 0, "msg": "success", "data": ... }`（code=0 成功）
- 说明：前端 dev 通过 Vite 代理 `/api` 访问；所有下载接口可直接浏览器打开。

## 1. 配置定义 `/api/defs`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/defs | 全部定义（含字段/依赖/生效与草稿行数） |
| GET | /api/defs/{code} | 单个定义 |
| POST | /api/defs | 创建（body=DefSaveRequest） |
| PUT | /api/defs/{code} | 更新 |
| DELETE | /api/defs/{code} | 删除（有数据行时 400） |
| POST | /api/defs/{code}/toggle | 启用/停用 |

DefSaveRequest：`{code, name, level(GLOBAL|REGION|PROJECT), description, fields[], dependsOn[], sortOrder, enabled}`
FieldDef：`{code, label, type(TEXT|TEXTAREA|NUMBER|BOOLEAN|DATE|SELECT|REFERENCE), required, options[], min, max, refDefCode, refFieldCode, defaultValue}`

## 2. 配置数据 `/api/data`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/data/rows?defCode=&published=&batchId=&scope=&page=&size= | 分页查询 |
| POST | /api/data/query | 带字段条件分页查询 {defCode, conditions:{字段:{op,value,value2}}, scope, published, batchId, page, size} |
| POST | /api/data/rows?defCode= | 新增行 {scope, data, published} |
| PUT | /api/data/rows/{id}?defCode= | 更新行 |
| DELETE | /api/data/rows/{id} | 删除行 |

条件操作符：`eq`/`contains`/`gt`/`lt`/`between`/`in`。

## 3. 导出 `/api/export`

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/export/tasks | 创建并启动 {defCodes[], conditions:{defCode:{字段:Cond}}}；返回任务快照（id 在 detail.id） |
| GET | /api/export/tasks | 任务列表（含快照与文件清单） |
| GET | /api/export/tasks/{id} | 快照（刷新恢复进度） |
| GET | /api/export/tasks/{id}/events | **SSE** 进度：snapshot/progress/done/ping |
| GET | /api/export/tasks/{id}/files/{defCode} | 下载单文件 xlsx |
| GET | /api/export/tasks/{id}/package?defCodes=a,b | 打包 zip（缺省全部；条目={编码}.xlsx） |

任务状态：PENDING/RUNNING/SUCCESS/FAILED；快照字段：{status, progress, message, detail:{id, files:[{defCode,defName,fileName,size,rowCount,level}], defCodes}}。
条件示例：`{"SERVER_PARAM":{"env":{"op":"eq","value":"生产"}}}`；地区/项目范围过滤用 `{"__scope__":{"op":"eq","value":"华东区"}}`。

## 4. 导入 `/api/import`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/import/templates?defCodes=a,b&zip=true | 模板下载（单 xlsx / zip） |
| POST | /api/import/batches | 创建批次 {name, defCodes} |
| POST | /api/import/batches/ensure | 幂等创建/复用批次（同配置组未发布批次） |
| GET | /api/import/batches | 批次列表 |
| GET | /api/import/batches/{id} | 批次快照 |
| GET | /api/import/batches/{id}/events | **SSE** 进度 |
| POST | /api/import/batches/{id}/files | 上传（multipart `files`，xlsx/zip 多文件）→ {matched[], unmatched[]} |
| GET | /api/import/batches/{id}/files/{defCode} | 下载已上传文件（编辑后覆盖上传） |
| POST | /api/import/batches/{id}/check | 启动检查（异步） |
| POST | /api/import/batches/{id}/import | 启动导入（异步） |
| POST | /api/import/batches/{id}/publish | 启动发布（异步；仅 IMPORTED 状态可） |
| GET | /api/import/batches/{id}/results | 每文件状态明细 |
| GET | /api/import/batches/{id}/issues/{defCode} | 检查问题明细 JSON |
| GET | /api/import/batches/{id}/errors/{defCode} | 错误明细 xlsx 下载 |
| GET | /api/import/batches/{id}/drafts/{defCode} | 草稿数据预览 |

批次状态：CREATED/CHECKING/CHECKED/IMPORTING/IMPORTED/PUBLISHING/PUBLISHED/FAILED。
文件状态：UPLOADED/CHECKED/IMPORTED/PUBLISHED/ERROR/SKIPPED。
Issue：`{level(ERROR|WARN), rowIndex, field, message, value}`。

## 5. AI `/api/ai`

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/ai/chat | **SSE** 对话 {sessionId, message, context} |
| POST | /api/ai/confirm | **SSE** HITL 确认 {sessionId, approved} |
| POST | /api/ai/clear | 清空会话 {sessionId} |
| GET | /api/ai/tools?page=export | 页面工具清单（渐进披露调试） |
| GET | /api/ai/sessions/count | 会话数 |

context 结构（摘要级快照）：
```json
{ "page": "export", "workspaceVersion": 3,
  "export": { "step": 1, "selectedDefs": [], "conditions": {}, "taskId": null },
  "import": { "step": 1, "selectedDefs": [], "batchId": null } }
```

SSE 事件：`reasoning{content}` / `delta{content}` / `tool_start{name,args}` / `tool_result{name,ok,summary}` / `ui_event{type,...}` / `done{content}` / `error{message}` / `usage{usage}`。

ui_event 类型：open_page/goto_step/select_defs/set_conditions/export_started/import_batch/import_action/download/refresh_defs/refresh_data/confirm_tool。

## 6. 元信息 `/api/meta`

GET /api/meta → {app, version, model, modelProvider, port, levels, time}

## 7. 任务中心 `/api/tasks`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/tasks?type=EXPORT\|IMPORT | 统一任务列表（导出任务与导入批次合并，按创建时间倒序） |

任务摘要：`{key: "EXPORT-3"/"IMPORT-2", taskType, taskTypeName, title, status, progress, message, defCodes[], filesCount, createdAt, updatedAt}`。
导出任务状态：PENDING/RUNNING/SUCCESS/FAILED；导入任务状态：CREATED/CHECKING/CHECKED/IMPORTING/IMPORTED/PUBLISHING/PUBLISHED/FAILED。
任务创建即持久化：导出 `POST /api/export/tasks`、导入 `POST /api/import/batches`（或 `/ensure`）落库后即可在列表中查询。
