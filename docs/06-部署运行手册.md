## 2. 端口约定与占用检测（启动前必做）

默认端口：**后端 18080**，**前端 5173**（8080 被外部 java 进程占用、8081 留给参考项目，均不触碰）。

检测命令：
```powershell
Get-NetTCPConnection -State Listen | Where-Object { $_.LocalPort -in 8080,8081,8082,18080,18081,5173,5174 } | Select-Object LocalPort, OwningProcess
```

若 18080 被占用：改 `backend/src/main/resources/application.yml` 中 `server.port`（支持环境变量 `SERVER_PORT` 覆盖），并同步改 `frontend/vite.config.js` 的 proxy target。
若 5173 被占用：改 `frontend/vite.config.js` 的 `server.port`。

> ⚠ 只允许停止自己启动的前后端进程；其他服务一律不碰。

## 3. 后端启动

```powershell
# 构建（首次较慢，需下载依赖）
$env:JAVA_HOME='D:\Program Files\Java\jdk-21.0.12'
& 'D:\Program Files\JetBrains\IntelliJ IDEA\plugins\maven-plugin\lib\maven3\bin\mvn.cmd' -f backend\pom.xml -DskipTests package

# 启动前必须设置 DeepSeek API 密钥（密钥禁止写入仓库）
$env:DEEPSEEK_API_KEY='你的DeepSeek密钥'

# 启动（工作目录=backend，H2 文件库落在 backend\data）
cd backend
& 'D:\Program Files\Java\jdk-21.0.12\bin\java.exe' -jar target\config-admin-backend.jar
```

- 首次启动自动初始化演示数据（4 个配置定义 + 生效数据行）。
- 健康检查：`GET http://127.0.0.1:18080/api/meta`。
- H2 控制台：`http://127.0.0.1:18080/h2-console`（JDBC URL `jdbc:h2:file:./data/config_admin_db`，用户 sa，空密码）。
- 重置数据：停止服务后删除 `backend\data` 目录再启动。

### 配置项速查（application.yml）

| 配置 | 默认 | 说明 |
|---|---|---|
| `server.port` | 18080 | 可用环境变量 SERVER_PORT 覆盖 |
| `spring.ai.openai.api-key` | 必填，无默认值 | 启动前设置环境变量 `DEEPSEEK_API_KEY`（密钥禁止写入仓库） |
| `spring.ai.openai.base-url` | https://api.deepseek.com | OpenAI 兼容端点 |
| `spring.ai.openai.chat.completions-path` | /chat/completions | 与给定地址一致 |
| `spring.ai.openai.chat.options.model` | deepseek-flash | DeepSeek-V4.1-Flash（推理模型） |
| `app.ai.max-tool-iterations` | 12 | Agent 循环上限 |
| `app.ai.session-ttl-minutes` | 30 | 会话空闲清理 |
| `app.task.simulate-delay-ms` | 5 | 演示用行级延迟（生产设 0） |

## 4. 前端启动

```powershell
cd frontend
yarn install   # 首次
yarn dev       # 开发服务器 http://127.0.0.1:5173（/api 代理到 18080）
yarn build     # 生产构建（dist/）
```

浏览器打开 `http://127.0.0.1:5173`。

## 5. SpreadJS 授权说明

@grapecity/spread-sheets 17.1.5 为商业组件。**未配置授权时为评估模式**：功能完整，表格区有水印提示（本项目已实测 ExcelIO 导入导出、在线编辑、数据验证往返均正常）。
正式使用：购买授权后在 `frontend/.env.local` 写入 `VITE_SPREADJS_KEY=你的授权码`（该文件已被 .gitignore 排除，重启 dev server 生效）。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 后端启动失败端口占用 | 按 §2 换端口（同步改前端 proxy） |
| AI 回复超时 | 检查 api.deepseek.com 可达性；`spring.ai.openai.read-timeout` 可调大 |
| AI 返回 400 | 多为 reasoning_content 回传问题，本实现已规避；若自行改造 Agent 循环请勿回传该字段 |
| 导入未匹配文件 | 文件名必须为 `{编码}.xlsx` 或 `{编码}(N).xlsx`（编码见配置定义列表） |
| 表格有水印 | 见 §5 授权说明 |
| H2 数据想重置 | 停服 → 删 backend\data → 重启 |
