## 1. 技术栈与工程基线（DC-05）

Vue 3 + **TypeScript（strict，禁用 any 泛滥）** + Vite 6 + Pinia + Vue Router +
Element Plus + TailwindCSS 3（preflight=false，kimi 蓝本实践）+ SpreadJS 17.1.5
（**接中文 Culture**，glm 蓝本 `main.js` 实践）+ axios（统一拦截器，glm 蓝本）。
TS 化顺序（Q9）：**types/ 契约层类型定义先行**，再 stores，再组件。
构建：manualChunks 分包（glm 蓝本 vite.config.js:27-34）；`yarn build` 必须绿。
代理：`/api` 代理目标用环境变量 `VITE_API_BASE`，**禁止硬编码端口**（G5 实测基座
硬编码 8081 是缺陷）。

## 3. 后端 API 对齐（S4.2/S4.3 现状，前端必须按此实现）

| 端点 | 说明 |
|---|---|
| `POST /api/ai/chat`（SSE） | 帧类型：`start`/`delta`/`tool_call`/`confirm_request`/`suspended`/`heartbeat`/`done`/`error`；完成帧校验（缺 done/error 终帧=断流，前端按 ADR-6 提示） |
| `POST /api/ai/confirm` | HITL 放行/拒绝；重复 toolCallId 幂等拒绝 |
| `POST /api/ai/frontend-tool-result` | 前端工具回灌（幂等：重复拒绝、未知 409） |
| `GET /api/ai/events/{runId}` | reattach 重挂（409 SESSION_BUSY 响应携 runId 时使用） |
| `POST /api/ai/cancel/{runId}` | 取消 AI 轮 |
| `GET /api/ai/history/{sessionId}` | 会话历史（刷新恢复用，配 sessionStorage 对账） |
| `GET /api/ai/health` | AI 可用性（503 降级提示） |
| 错误码 | `409 SESSION_BUSY`（携 runId）/ `503 SUSPEND_POOL_SATURATED` / `503 AI_UNAVAILABLE` / `503 AI_REDIS_UNAVAILABLE` / `409 JOB_ALREADY_FINAL` |
| 任务/作业 | 任务中心分页（createdAt DESC,id DESC）/ 过滤 / keyword 转义已后端处理；进度为**行级口径**（processed/total，total 未知=-1 → 前端显示"处理中"不显示百分比） |
| 发布冲突 | **异步形态（Q4）**：发布请求恒 201，冲突表现为作业 FAILED + `GET /api/jobs/{id}/issues` 文案——前端必须轮询/订阅作业终态后查 issues 展示，禁止按同步错误处理 |
| 取消/删除 | `DELETE /api/jobs/{id}` 取消（终态 409）；任务删除级联清理（S4.3b⑦） |

执行中/挂起等待区分（N6 裁决）：按 SSE 帧类型渲染（`suspended`/`confirm_request`=挂起等待，`delta`=生成中）。

## 4. 页面与结构

```
frontend/src/
  types/        # 契约层类型（API 模型、SSE 帧、工具契约、任务/作业/定义）——先行
  api/          # axios 实例、sse.ts（EventSource 封装+重连）、各域 client
  stores/       # ai.ts / workspace.ts / task.ts（Pinia + TS）
  views/        # TaskCenterView / ExportWizardView / ImportWizardView /
                # DefinitionsView / DataBrowserView
  components/   # AiPanel / TaskWizard(壳) / wizard/* (体) / SpreadGrid / JobProgress
  utils/        # excel.ts(动态校验/JSZip) / frontend-tools.ts
```

- 五页齐备：任务中心（4s 自刷+一键恢复）、导出向导（3 步）、导入向导（4 步）、
  配置定义、数据浏览（FR-1.1）
- 向导壳体分离；进度条行级口径；步进条状态映射以任务状态机为准
- AI 面板常驻右栏；**裁剪性（ADR-10 回归用例）：隐藏 AI 栏后全部业务功能可用**

## 5. 出口标准

1. `yarn build` 绿（TS strict 无 error）；
2. 双向导走查：导出（选配置→条件→导出→进度→下载）与导入（模板/上传→检查→
   导入→发布）全通；
3. AI 联动：AI 驱动导出+导入（渐进披露子集正确、HITL 确认/拒绝双路径、
   工具卡四态、思考链折叠）；
4. 刷新恢复：AI 对话刷新页面历史不丢（sessionStorage+对账）；工作区任务状态正确；
5. 冲突提示：并发发布冲突按 Q4 异步形态正确展示（作业 FAILED + issues 文案）；
6. 409/reattach：运行中重复发起得到 409 并一键 reattach；
7. 裁剪性：去 AI 栏业务全流程可用（录屏或截图证据）；
8. 全中文 UI（DC-06①）。
