# 区域费率管理口径（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。

## 1 定义

区域费率（REGION_TARIFF）是配置管理平台按「区域 + 币种 + 档位」维度维护的价格参数集合。它决定导出、结算与预算三类业务的计价基准，是 GLM 种子域中的核心配置之一。

费率不是财务凭证，不能在费率表里记录结算结果；结算结果属于业务数据，走独立的结算库。

## 2 关键字段

| 字段 | 含义 | 必填 | 备注 |
| --- | --- | --- | --- |
| region_code | 区域编码 | 是 | 来自 REGION 定义 |
| currency | 币种 | 是 | 来自 CURRENCY 定义 |
| level | 档位 | 是 | A/B/C |
| base_rate | 标准费率 | 是 | 大于 0 |
| cross_ratio | 跨区加收比例 | 否 | 0–30% |

## 3 维护规则

1. 新增费率必须同时提供三元组与标准费率，缺一不可；
2. 修改标准费率必须走变更审批，不允许直接编辑生效版本；
3. 停用区域前必须先确认该区域没有有效费率；
4. 批量维护优先走导入流程，不逐条手工修改；
5. 同一三元组不允许重复记录。

## 4 常见问题

**问：费率表在哪里维护？**
答：在配置管理平台的「配置定义 → REGION_TARIFF → 数据浏览」中查看，修改走导出/导入流程。

**问：口头说的"区域价格"指什么？**
答：就是区域费率，二者是同一个配置域。

**问：标准费率和基准费率有区别吗？**
答：没有。基准费率是标准费率的另一种叫法，字段都是 `base_rate`。
