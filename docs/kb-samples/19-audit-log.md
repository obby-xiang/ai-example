# 操作审计与留痕（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。

## 1 审计范围

以下动作必须留痕：定义发布、数据导入、数据发布、任务创建、作业发起、成员角色变更、阈值变更、知识库热重载。

只读动作（查询、导出、检索）默认不留业务审计，但保留访问日志。

## 2 审计字段

| 字段 | 说明 |
| --- | --- |
| 操作人 | 账号 + 姓名 |
| 操作时间 | 精确到秒 |
| 操作类型 | 发布/导入/变更等 |
| 目标对象 | 定义编码或数据主键 |
| 变更摘要 | 变更前后摘要，不含完整数据 |
| 关联单号 | 变更单/工单编号 |
| 结果 | 成功/失败 + 失败原因码 |

## 3 保留期限

业务审计保留三十六个月；访问日志保留六个月；作业日志保留十二个月。到期后归档，不直接删除。

## 4 查询与导出

审计查询按时间范围 + 操作类型检索；跨项目查询需要授权。导出审计记录需要审批，导出文件加密保存。

## 5 常见问题

**问：审计记录可以修改吗？**
答：不可以。审计只追加，发现记录错误时以补充说明的方式追加，不覆盖原记录。

**问：AI 发起的操作有审计吗？**
答：有。AI 发起的写操作与人工操作走同一审计链路，并额外记录会话标识。

**问：热重载为什么也要审计？**
答：热重载会改变模型可检索的知识面，属于影响回答口径的动作，必须可追溯。
