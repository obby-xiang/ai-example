# 数据质量校验规则（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。数字为演示值。

## 1 校验分层

数据质量校验分为三层：格式校验、业务校验、跨域校验。三层按顺序执行，前一层不通过时不进入下一层。

## 2 格式校验

| 规则 | 判据 | 失败处理 |
| --- | --- | --- |
| 必填 | 字段值非空且非空白 | 拒绝导入 |
| 长度 | 不超过定义长度 | 拒绝导入 |
| 类型 | 与字段类型一致 | 拒绝导入 |
| 日期 | `yyyy-MM-dd` 且真实存在 | 拒绝导入 |
| 小数位 | 不超过定义精度 | 拒绝导入 |

## 3 业务校验

1. 主键唯一：同一主键组合只能出现一次；
2. 枚举合法：值必须在定义枚举内；
3. 数值区间：费率 > 0、比例 0–30%；
4. 状态合法：状态值必须来自状态枚举；
5. 生效日期：不得早于定义的最小生效日期。

## 4 跨域校验

- 区域编码必须存在且有效；
- 币种编码必须存在且有效；
- 项目环境引用的区域必须存在；
- 项目成员引用的项目必须存在；
- 费率引用的档位必须存在。

跨域校验依赖的定义必须已发布；定义未发布时校验会提示"无法校验引用"，此时不能强行导入。

## 5 质量指标

| 指标 | 计算方式 | 目标 |
| --- | --- | --- |
| 一次通过率 | 首次预检查通过批次数 / 总批次数 | ≥ 90% |
| 主键重复率 | 重复行数 / 总行数 | ≤ 0.1% |
| 空值率 | 必填字段空值数 / 必填字段总数 | 0 |
| 引用缺失率 | 引用缺失行数 / 总行数 | ≤ 0.5% |

指标按月统计，低于目标时先分析原因，再决定是修数据还是修规则。

## 6 处置建议

- 格式问题：修文件，不要改定义迁就数据；
- 业务问题：核对业务口径，必要时更新定义；
- 跨域问题：先补引用数据，再导入；
- 批量问题：抽样定位模式，避免逐行修。
