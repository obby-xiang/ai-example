# 发布前检查清单（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。

## 1 数据检查

- [ ] 导入文件的行数与导出快照的预期行数一致；
- [ ] 主键列没有空值、没有重复；
- [ ] 必填列全部有值；
- [ ] 枚举列的取值都在定义范围内；
- [ ] 引用列（区域/币种/项目/成员）都能找到对应记录；
- [ ] 数值列的精度与定义一致（小数位数不超限）；
- [ ] 日期列格式为 `yyyy-MM-dd`，没有非法日期；
- [ ] 文本列没有超长（超过定义长度会被拒绝）；
- [ ] 没有明显的测试数据混入（如"测试""test""示例"字样）；
- [ ] 变更行数与变更单描述一致。

## 2 定义检查

- [ ] 引用的配置定义都已发布；
- [ ] 定义版本与导入文件使用的模板版本一致；
- [ ] 没有引用已停用的定义；
- [ ] 新增字段已经发布，旧字段没有被删除。

## 3 流程检查

- [ ] 变更单已审批；
- [ ] 当前没有同配置域的在途作业；
- [ ] 发布窗口已确认；
- [ ] 当前数据快照已导出留档；
- [ ] 回退方案已写明。

## 4 发布后检查

- [ ] 作业状态为成功；
- [ ] 抽检三条记录与导入文件一致；
- [ ] 相关页面数据显示正常；
- [ ] 没有新增告警；
- [ ] 变更单已回填作业编号；
- [ ] 通知相关方发布完成。

## 5 使用说明

清单逐项确认，不允许"整体确认"。任何一项未通过时，先修正再发布；确因客观原因无法确认的，在变更单中注明并由审批人签字。
