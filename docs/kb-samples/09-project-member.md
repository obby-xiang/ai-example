# 项目成员与角色（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。

## 1 定义

项目成员（PROJECT_MEMBER）记录"谁在哪个项目里担任什么角色"。它不等同于系统账号：账号决定能否登录，项目成员决定登录后能操作哪些项目数据。

## 2 角色

| 角色编码 | 名称 | 可查看 | 可编辑 | 可发布 | 说明 |
| --- | --- | --- | --- | --- | --- |
| VIEWER | 查看者 | 是 | 否 | 否 | 只读 |
| EDITOR | 编辑者 | 是 | 是 | 否 | 可建草稿 |
| PUBLISHER | 发布者 | 是 | 是 | 是 | 仅配置管理员授予 |
| OWNER | 负责人 | 是 | 是 | 否 | 可管理成员 |

## 3 规则

1. 每个项目至少有一个 OWNER；
2. 同一人在同一项目只能有一个角色；
3. PUBLISHER 由配置管理员授予，项目经理不能自行授予；
4. 成员离职时先移除成员关系，再停用账号；
5. 角色变更记录保留不少于二十四个月。

## 4 常见问题

**问：项目成员和项目环境有关系吗？**
答：没有直接隶属关系。成员属于项目，环境属于项目；成员角色不影响环境状态。

**问：为什么我看不到某个项目？**
答：先确认是否是该项目成员；不是成员时联系 OWNER 添加。

**问：OWNER 可以移除自己吗？**
答：不可以。必须先把 OWNER 转给其他人，再移除自己。
