# 术语表（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。

## 1 业务术语

| 术语 | 口头叫法 | 含义 | 所属域 |
| --- | --- | --- | --- |
| 标准费率 | 基准费率、基础价 | 区域内默认档位费率 | REGION_TARIFF |
| 区域费率 | 费率表、区域价格 | 区域级价格参数集合 | REGION_TARIFF |
| 跨区加收比例 | 加收比例、跨区系数 | 跨区结算的加价比例 | REGION_TARIFF |
| 档位 | 等级、级别 | 费率层级 A/B/C | REGION_TARIFF |
| 项目环境 | 环境清单、环境 | 项目可用运行环境集合 | PROJECT_ENV |
| 告警阈值 | 告警线、阈值线 | 触发告警的边界值 | ALARM_THRESHOLD |
| 观察期 | 试运行期 | 变更后的观察时间窗 | ALARM_THRESHOLD |
| 项目成员 | 成员、项目人员 | 项目内的人与角色关系 | PROJECT_MEMBER |
| 预检查 | 导入检查 | 导入前的格式与依赖校验 | 通用流程 |
| 发布 | 上线、生效 | 把暂存数据写入正式库 | 通用流程 |

## 2 技术术语

| 术语 | 含义 |
| --- | --- |
| 定义（Definition） | 一类配置的字段结构 |
| 数据（Data） | 按定义落库的具体记录 |
| 主键（Key） | 唯一定位一条记录的字段组合 |
| 引用（Ref） | 字段值受另一份定义约束 |
| 暂存区 | 导入后、发布前的中间区域 |

## 3 使用约定

同一术语在检索时可能以口头叫法出现；知识库的别名索引会把口头叫法映射回正式术语。精确查询术语解释用 `kb_lookup_term`，模糊召回用 `kb_search`。
