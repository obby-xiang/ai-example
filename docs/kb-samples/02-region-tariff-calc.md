# 区域费率计算规则（样例）

> 本文为**样例文档**，仅用于知识库功能验证，不含真实业务数据。数字均为演示值。

## 1 单笔计算

应收金额 = 业务量 × 标准费率 × 档位系数。档位系数 A=1.00、B=1.05、C=1.10。金额只在最终结果取整到分，中间步骤不取整。

示例：业务量 87，标准费率 4.25，档位 B ⇒ 87 × 4.25 × 1.05 = 388.24（四舍五入到分）。

## 2 跨区加收

跨区金额 = 业务量 × 业务发生地费率 × 档位系数 ×（1 + 跨区加收比例）。注意：比例读取业务发生地所属区域，不是费率所属区域。

示例：业务量 200，发生地费率 1.80，档位 A，比例 7.5% ⇒ 200 × 1.80 × 1.00 × 1.075 = 387.00。

## 3 取整与边界

| 场景 | 处理 |
| --- | --- |
| 费率 ≤ 0 | 拒绝发布 |
| 费率 > 9999.99 | 需要二次确认 |
| 跨区比例 < 0 或 > 30% | 拒绝保存 |
| 跨区比例非 0.5% 整数倍 | 拒绝保存 |
| 最终金额 | 四舍五入到分 |

## 4 校验顺序

1. 先校验定义引用（区域/币种/档位是否存在）；
2. 再校验数值区间与步长；
3. 最后校验生效日期冲突。

顺序不能反：先校验日期会在定义缺失时给出误导性的冲突提示。

## 5 排障提示

金额不一致时，按「档位系数 → 跨区比例来源 → 取整时机」三步复算。90% 的差异来自跨区比例读错区域，10% 来自中间步骤提前取整。
