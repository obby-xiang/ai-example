## 1. 最终型谱（2026-10-17 用户直裁）

### 1.1 H1 · 批准 / 拒绝

- **仅两钮**（批准 / 拒绝），**无理由框**。
- **独立成步**（不与 H2 / H3 混在同一屏内联）。
- **超时兜底**（超时即已决，不挂「等待确认」）。
- **修正走会话**：拒绝后由对话修正，AI **重新提案**。
- **不采纳挂账两型**：「修改后批准（inline）」与「暂不处理」—— 不采纳，登记挂账。

### 1.2 H2 · 选择

- **单选 / 多选**。
- **选项 ≤ 5**（不含「其它」）。
- **「其它 + 输入框」为可配项**（按场景配置，不是默认必有）。
- **封闭策略集禁挂「其它」**：如「覆盖 / 跳过 / 中止」这类封闭策略集，不得挂「其它」。
- **审计口径两档**：审批选择**重审计**、参数选择**轻审计**。

### 1.3 H3 · 缺失输入

- **仅输入框** + **必填校验** + **取消出口**。

### 1.4 GF 表单系

- **多字段采集保留**（GF 不与 H2 / H3 合并）。
- **枚举初值合法默认**（初值必须落在合法枚举内，不出现空串 / 非法值）。

### 1.5 步进

- **步序组合**：H1 **独立成步**；H2 / H3 **可组合混排**（同一步内混排）。
- **四控件**：
  - **上一步**：非首步可用；
  - **下一步**：非末步、且当前步已处理可用；
  - **取消**：全程可用 —— 放弃整个流程、**输入作废**、AI 收「已取消」、**审计留痕**；
  - **提交**：末步、且已处理可用。
- **不设「跳过」**；可选性**下沉到字段级**（如选项里给「不限制」、字段允许留空合法）。
- **进度 N/M**（步序计数展示）。
- **已完成折叠**成摘要行 + 终了 **review 汇总页**：只复述已知事实、**可回改**。
- **逐步只读卡永久保留**（每一步决策后的只读卡不折叠、不销毁）。
- **全部处理完才恢复运行** = **CopilotKit 语义**（流程未走完全部步序，run 不恢复）。
