## 1. 最终型谱（2026-10-17 用户直裁）

### 1.1 H1 · 批准 / 拒绝

- **仅两钮**（批准 / 拒绝），**无理由框**。
- **独立成步**（不与 H2 / H3 混在同一屏内联）。
- **超时兜底**（超时即已决，不挂「等待确认」）。
- **修正走会话**：拒绝后由对话修正，AI **重新提案**。
- **不采纳挂账两型**：「修改后批准（inline）」与「暂不处理」—— 不采纳，登记挂账。

### 1.2 H2 · 选择

- **单选 / 多选**。
- **选项 ≤ 5**（不含「其它」）。
- **「其它 + 输入框」为可配项**（按场景配置，不是默认必有）。
- **封闭策略集禁挂「其它」**：如「覆盖 / 跳过 / 中止」这类封闭策略集，不得挂「其它」。
- **审计口径两档**：审批选择**重审计**、参数选择**轻审计**。

### 1.3 H3 · 缺失输入

- **仅输入框** + **必填校验** + **取消出口**。

### 1.4 GF 表单系

- **多字段采集保留**（GF 不与 H2 / H3 合并）。
- **枚举初值合法默认**（初值必须落在合法枚举内，不出现空串 / 非法值）。

### 1.5 步进

- **步序组合**：H1 **独立成步**；H2 / H3 **可组合混排**（同一步内混排）。
- **四控件**：
  - **上一步**：非首步可用；
  - **下一步**：非末步、且当前步已处理可用；
  - **取消**：全程可用 —— 放弃整个流程、**输入作废**、AI 收「已取消」、**审计留痕**；
  - **提交**：末步、且已处理可用。
- **不设「跳过」**；可选性**下沉到字段级**（如选项里给「不限制」、字段允许留空合法）。
- **进度 N/M**（步序计数展示）。
- **已完成折叠**成摘要行 + 终了 **review 汇总页**：只复述已知事实、**可回改**。
- **逐步只读卡永久保留**（每一步决策后的只读卡不折叠、不销毁）。
- **全部处理完才恢复运行** = **CopilotKit 语义**（流程未走完全部步序，run 不恢复）。

## 8. 追加注记 · 2026-10-17（用户口头裁决 R1~R5 · 覆盖本件部分口径）

> 性质：**追加注记，上文原文冻结不改**。本节优先级高于本件正文；凡与本节冲突的条文（尤其 §1.1「H1 独立成步」与上一版 demo 的「已不执行」徽标）按本节执行，原文保留仅作历史存档。
> 施工落点：`docs/demo/chat-ux/hitl-interrupts.html`（r2 场景廊 S1–S7，commit `74f5f37`）。

用户 2026-10-17 口头裁决五条（原文要点）：

- **R1**：「批准 / 拒绝」只能单独存在 = 单步独立审批卡，绝不能出现在 HITL 多步流（步进向导）内；多步流里只有选择 / 输入类步骤，步进控件也不含批准 / 拒绝语义。
- **R2**：不做按钮禁用态：当前不可用的按钮直接不渲染（隐藏），不要 disabled 灰钮。
- **R3**：所有操作按钮一律底部靠右排列（flex 右对齐），禁止居中；视觉与 demo 族协调。
- **R4**：多选必须用复选框（checkbox），「其它」也是复选框列表里的一行选项（勾选后展开文字输入）；所有选项（单选多选都含）一行一个，禁止一行多个 / 胶囊横排。
- **R5**：删除「已不执行」结果态：审批结果只有 已批准 / 已拒绝；另有 已超时 / 已取消。

被推翻的本件口径（只列冲突项，不重写原文）：

1. §1.1「H1 独立成步」→ 收紧为「H1 只以独立单步卡存在，不得并入多步向导」；正文「步进 = H1 独立成步 + H2 / H3 可混排」的混排口径作废（多步流只允许选择 / 输入步骤）。
2. 正文与上一版 demo 的「已不执行」第三态徽标 → 由 R5 删除；审批终态仅 已批准 / 已拒绝，另有 已超时 / 已取消 两个事件态。
3. 「四控件 + 不设跳过」中把不可用控件置灰的做法 → 由 R2 改为不可用即不渲染。
4. H2 选项横排 / 胶囊式呈现 → 由 R4 改为单选 / 复选框逐行、一行一个，「其它」占一行，勾选后展开输入。
5. 操作按钮居中或左置的排布 → 由 R3 统一为底部靠右一行、主钮最右。

影响面：问题2 批次 2C（H2 / H3 新卡型 + 步进）以 R1~R5 为准；本件其余条款（审批策略与审计分级、批次 2A / 2B / 2D、只读态两套语义）不受影响。
