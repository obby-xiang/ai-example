## 2. 已确定但不等于已落实的项目口径

以下只是施工必须执行的裁决，不是当前生产行为：

1. 四条语言通道分别治理；模型侧提示词和工具定义维持稳定中文单语。
2. 原始工具结果不自动机器翻译；系统生成的静态标签、状态和错误仍须完整本地化。
3. 固定 emoji 短指令为：

   ```text
   跟随用户语言，简洁专业，保留必要术语和原始标识；未明确要求时不新增emoji，原文既有符号不清理。
   ```

4. 不限制 Markdown，不清理原文既有符号。
5. AI 工具确认采用“批准具体动作/不执行”；不可逆确认采用结果型按钮，二者均属于呈现规格变化。
6. 本批计划不改工具 Schema、API/SSE/Redis、状态机、确认门、执行逻辑、Markdown 渲染和业务逻辑。
