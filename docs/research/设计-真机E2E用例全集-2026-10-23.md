## 0 口径

### 0.1 载体与触发（三条硬约束）

| 项 | 口径 |
|---|---|
| 载体 | **Playwright（`@playwright/test`）驱动真 Chromium + 真后端进程 + Redis**；页面交互全部走真实鼠标/键盘事件（`page.mouse` / `page.keyboard`），禁 `element.click()` 语义替代（GF 开关、hover 显现、拖拽选区必须在真机层做） |
| 模型 | **真 key**（`OpenAI` 兼容网关，默认 DeepSeek 端点）。key 只从 CI secret / 环境变量注入，**不入库、不进日志、不进 trace、不进截图** |
| 触发 | **手工触发，不随 push**：`workflow_dispatch`（或仓外手工 job），参数含 `suite`（域组）、`sample`（概率例采样数）、`base`（是否对基线桩跑） |
| 实例 | harness **自己起**后端与前端 dev server（独立端口段，默认 `18330` / `5202` 之外的端口），跑完即停；**绝不占用常开的 8081 / 5202**；每个 worker 独立 `sessionStorage`（独立 browser context） |
| 时序 | 一律**显式等待条件**（`expect(...).toPass()` / `waitForFunction`），禁固定 `sleep` 断言；超时上限守卫（单例 ≤ 120s，长跑例单列预算） |

### 0.2 断言强度分级

| 级 | 名称 | 判据形态 | 判红条件 | 允许 flake 重试 |
|---|---|---|---|---|
| **A** | 界面可见 | DOM 结构 / `data-testid` 存在与终态文本 / 可见性 / 禁用态 / `aria-*` / 计算样式（`pointer-events`、`opacity`） | 任一断言不成立即红，**零容忍** | 0（A 级 flake 视为缺陷） |
| **B** | 协议正确 | 请求体/响应码/响应头、SSE 帧序与 `seq` 单调、落档（`/runs/{id}`、`/pending/{id}`、`/history/{sid}`、`/context/{sid}`）三方同值、`sessionStorage` 键值 | 逐字段比对不等即红 | 0 |
| **C** | 模型行为概率性 | 「模型是否按提示词做了某事」（调某工具、给结构化建议、抵抗注入） | 见 §0.3 采样口径 | 1（重试后仍低于阈值即红） |

**A 级专用纪律**：断言只落 `data-testid` 与终态文本，**不断言动画中间态、不断言像素坐标、不断言行高/间距**（视觉验收不在本件，见 §3.3）；`mmd-viewer`/`sheet-preview` 这类 SVG/网格只断言「元素在 + 缩放百分比文案变化」这类离散量。

### 0.3 概率口径（C 级专用）

| 类别 | 采样 N | 阈值 | 升级规则 |
|---|---|---|---|
| 常规行为（触发工具、给建议、引用格式） | 10 | **≥ 7** | 连续 3 次运行低于阈值 ⇒ 升级为红（判回归），单次低阈值只开 issue |
| 安全类（提示词注入抵抗、越 scope 工具不调） | 10 | **≥ 9** | 一次低于阈值即开 issue 并标记 P0 观察 |
| 成本敏感（长上下文、多轮压缩） | 5 | ≥ 4 | 须在用例行内注明 `N=5` 及理由 |

**C 级断言只能断「形状 + 概率下限」，禁逐字比对模型输出**；形状指：工具名 ∈ 允许集、入参 JSON 合法且键集在声明内、回复非空且不含内部标记（`<knowledge>`、`toolCallId=`）等。

### 0.4 「真机」与「桩」的边界

- 标 `层 = UI` 的用例：真浏览器 + 真后端 + **真 key**，除非「前置」列写了 `桩 <开关>`。
- 标 `层 = API` 的用例：Playwright `request` 上下文直打 HTTP/SSE，不经 DOM；仍要真后端进程（用于验证落档与时序）。
- **故障注入一律走桩**（`stall-frames` / `kill-stream` / `slow-tool` / `break-at-seq` 等 24 个开关）：真上游无法确定性制造「在 K 处断」「慢 130s」。桩启用的用例**断言不得落在模型语义上**（只断形状与时序）。
- 桩与真 key 同一 harness 内可选：`suite=real`（真模型）/ `suite=stub`（确定性）/ `suite=both`（同一断言两跑，用于检测「修好了只在桩下对」）。

### 0.5 编号与证据命名

- 编号：`E2E-<域码><两位>`（如 `E2E-R01`、`E2E-V07`、`E2E-MD03`）。域码见 §1 与附录 A。
- 与既有编号的关系：`S-01`…`X-13` 沿用 2026-10-22 蓝本编号（已被 `verify-e2e.ps1` 用作 `Add-AiCase` id），本件**不重编号**，只补「真机层断言」与「锚点」两列；新增域从 `V`（可视可操作）、`N`（会话）、`F`（反馈与消息操作）、`A`（附件）、`E`（空态与错误面）、`Z`（结果视图）、`U`（撤销）、`I`（i18n）、`Y`（配置页）、`O`（并发）、`MD`（渲染）、`L`（工具全量）起号。
- 证据落盘（仓外，不入库）：`<仓外证据目录>/e2e-real/<用例编号>/`，含 `trace.zip` / `screenshot.png`（终态）/ `sse.txt`（逐帧）/ `http.txt`（请求响应原文）/ `console.txt`。**trace 与截图在含 key 的请求头与用户正文处必须已脱敏**（Playwright `redact` + 请求头过滤）。

### 0.6 六条「不算覆盖」

1. **SKIP 不算过**：真机层零 SKIP 底线（缺前置 ⇒ 整棒 FAIL，不静默跳过）；唯一允许 SKIP 的是 C 级「模型未触发」且该例已在报告里单列计数。
2. **只截屏不算断言**：每例必须有 ≥1 条 A 级或 B 级断言；纯截图例视为无断言。
3. **与既有单测逐字同义不算新增**：真机例必须含一条「jsdom/纯函数结构上做不到」的判据（真重载 / 真鼠标 / 真 SSE 生命周期 / 跨进程时序 / 真上游）。
4. **概率例不到采样数不算跑**：`N` 不足即计入「未完成」，不得记为通过。
5. **桩下过、真 key 下未跑不算过**：标 `真模型` 的用例必须在真 key 下跑过。
6. **同一断言在两处重复登记不算两条**：一条用例只能有一个「主断言面」，重复即合并（§4.5）。

## 3 覆盖对账（代码面 ↔ 用例双向）

### 3.0 方法与三条机器可核判据

对账是**双向**的，两个方向都必须成立才叫零遗漏：

- **正向**（代码面 → 用例）：把代码盘点得到的**每一个功能面/分支**逐项列出，指向至少一条用例（§3.1）。
- **反向**（用例 → 代码面）：§2 的 301 行**每行都有一列「锚点」**，把该列收集去重即得反向映射（**440 个不同锚点**）；不需要另建一张表 —— 两处维护必然漂移。

**三条判据（可用脚本核）**：

| 1 | 用例编号在本域内连续（`01…N` 无洞）、全局唯一 | 301 个编号全唯一、每域连续 |
| 2 | 每条用例的「锚点」列非空（≥1 项） | 301/301 非空 |
| 3 | 每个代码面至少映射 1 条用例，或明确列入 §3.3「不适用 + 理由」 | 见 §3.4 计数对账（无「既无用例又不适用」的面） |

### 4.5 去重判据（三条，写用例时逐条自检）

1. **一例一面**：一条用例只有一个「主断言面」（列在断言首句）。若两个面必须同时验，拆成两条并交叉引用。
2. **必须含「单测做不到」的判据**：每条真机用例至少 1 条 A 级（真 DOM）或 B 级（真连接/真落档）断言；否则降级为单测，不进本件。
3. **与 spec 逐字同义的断言必须删**：例如「`stop()` 后 `suspended=false`」已由 `rg-round-restore-stop` 锁住，真机只断言「输入框真的可输入」这一可见面。

> 与 2026-10-22 蓝本 §5 判据 4（「不与单测重复」）的关系：本件**继承**该判据并把它**写进用例行**（§2 每行的断言一律从「现象」起句，不从「状态变量」起句），因此不需要再维护一张「已覆盖」标记表。
