## Task 1：续跑上下文刷新与表单幻影

### 根因

生产 `park.enabled=true` 时，create_task/navigate_to/confirm_step 在唯一上下文刷新点之前挂起；续跑一直使用请求边界的旧 context，导致步骤工具不披露。FORM_SLOTS_ALREADY_KNOWN 被拒绝后仍发 tool_start/frontend_tool_result，前端又把所有非成功状态显示成“已取消”。

### 修改

1. 续跑工具批全部结算后，按真实成功结果统一刷新上下文；随后重新读取快照 context，再构造下一跳。不得在 resolvePending 内逐条刷新，不得破坏批内授权冻结。
2. 刷新后给模型提供权威工作区状态更新，保留 tool_use/tool_result 配对与顺序。
3. 对 generative_form + FORM_SLOTS_ALREADY_KNOWN，后端保留条目、日志和模型 ToolResponse，但不发送会产生用户卡片的工具帧；前端隐藏该错误码的历史幻影卡。
4. 只有真实用户取消显示“已取消”；rejected/expired/failed 不得统一误标。
5. 不回退 select_definitions 等工具的 scope；contextRefresher 缺失补可观测性，不把可选注入当成已证根因。

### 测试

- park=true：create_task 批准并 navigate_to 成功后，下一跳 context 含 EXPORT/SELECT_DEFS，工具集含 select_definitions。
- 连续推进 QUERY_COND、EXPORT 后分别披露 set_condition、start_export；同一批不扩权。
- 已知 CURRENCY/CNY：无 generative_form 请求、无幻影工具卡、模型仍收到纠正回执。
- 未知或歧义配置：表单仍正常可用，防止修复过度。
- rejected/expired/failed/cancelled 的展示语义分离；历史 FORM_SLOTS_ALREADY_KNOWN 不显示卡片。
- 真机 E2E：导出 CNY 货币字典完整通过创建、导航、选配置、推进、设条件，且全程无冗余表单。

## Task 2：M08 探测与重连

### 根因

trace 证明 10 个 HTTP 请求是 5 条 EventSource + 5 条 probe fetch，不是双 SSE。probe 打正式 SSE 端点会订阅、回放、续期，并阻塞退避时间线。

### 修改

1. 新增同路径 `?probe=1` 的轻量 JSON 探测，复用 preparingOrUnknown；不得创建 SseEmitter、回放、订阅或 touchActiveRun。
2. 前端 probe 使用 JSON Accept；探测不得阻塞既有 1/2/4/8 秒重连退避，保留 202/404/503 语义。
3. E2E 只统计 resourceType=eventsource；保留真实连接不超过 5 次和退避断言，不放宽阈值。

### 测试

- 探测 202/404/503 状态正确，且零订阅、零回放、零续期。
- 探测失败或挂起不推迟首次重连。
- M08 真机只计 EventSource，1+4 预算和 1/2/4/8 秒退避通过。
- 成功挂起路径仍只有一条真实连接，AR-06 准备中语义不回退。

## Task 3：C13 上下文预算与安全续跑

### 根因

轮首和压缩后基线漏算 system/tools；工具结果固定 20000 字符且最近 5 对不可清，小窗口下必然越窗；工具落定后越窗没有压缩固定历史的安全续跑；WRAP_UP_IGNORED 与真越窗共用错误码。

### 修改

1. 预算包含 system+tools+history+新输入+输出预留，按实际 max_context 校验 reserve，避免退化分母。
2. 在 modelData → ToolResultEnvelope → ToolResultLimiter 同一模型侧写入口按剩余窗口收缩；复用截断元数据和完整台账，不引入新存储体系。
3. 仍超窗时允许收缩最新未保护工具结果，保持 tool_use/tool_result 配对和 HITL 保护。
4. 越窗恢复只压缩并重放固定历史、仅调用模型；已执行工具不得重跑。
5. WRAP_UP_IGNORED 使用独立工具预算耗尽原因，不再冒充 CONTEXT_OVERFLOW。

### 测试

- system/tools 纳入轮首与压缩后判据。
- 15000 窗口下多条大工具结果按剩余预算收缩，截断元数据与台账完整。
- 最新未保护结果可收缩，HITL 保护条目不动，工具配对合法。
- 越窗后续跑只调模型，副作用工具执行次数不增加。
- WRAP_UP_IGNORED 与真越窗错误原因可区分。
- 真机 C13 多工具场景无 CONTEXT_OVERFLOW_AFTER_TOOL_SIDE_EFFECT；若暴露新的生产缺陷，不得豁免测试。
