### Q1 工具与文本不交错、工具堆一起

**现象**：一轮里正文与工具卡不交错；一批工具调用聚成一坨。

**根因（三步证据）**
1. 渲染真值是**有序段数组** `parts`，不是按类型分桶：`frontend/src/types/ai.ts:200`、`frontend/src/types/ai.ts:271`；面板仅做块分派 `frontend/src/components/AiPanel/AiPanel.vue:591`→`frontend/src/utils/blocks.ts:87`。
2. **实时序 = 帧序，正确**：文本增量只续写/追加到末尾段 `frontend/src/utils/parts.ts:44-61`；工具段新建时封口末段后 push `frontend/src/utils/parts.ts:101-102`。所以实时路径不丢序。
3. **丢序在历史还原**：每条 ASSISTANT 历史条目一律拼成 `[text(seg 0), …toolCalls]`，正文恒定排在所有工具之前：`frontend/src/stores/ai.ts:708-711`。历史载荷除 type/text/toolCalls 外不携带相对时序（`frontend/src/types/ai.ts:134-143`），故刷新/重挂后"工具→正文"的真实交错被改写成"正文→整批工具"。
4. **视觉放大**：相邻活动段被合并成一个折叠组（`frontend/src/utils/blocks.ts:130-132` + `AiPanel.vue:171-184`），一批并行调用天然相邻 ⇒ 看起来"堆一起"（分组不改顺序，是叠加因素）。

**修法方向**：历史还原按后端条目序插段（空 text 的 ASSISTANT 条目走工具段、TOOL 条目回填结果），或让后端历史带段序/时序字段，前端按序重建 parts。

### Q2 工具响应被硬截断

**现象**：工具结果卡片里内容在中间断掉。

**根因**：前端**零截断**（全仓 `frontend/src` 搜 `truncat/substring/.slice(MAX_` 无工具结果命中）；帧侧也是全文（`backend/.../ai/gate/SpToolCallingManager.java:488-490` 的 `frameText` 是恒等函数，同类 javadoc `:64` 明示"帧 resultText 全文不裁剪"）。硬截断在后端两处：

- **8000 字符 / 200 行（历史可见的那一份）**：`backend/.../ai/tool/ToolResultLimiter.java:56-61`（超行留前 N 行、超字符截到 `maxChars`），上限值 `backend/.../ai/config/AiProperties.java:327,330`、`backend/src/main/resources/application.yml:162-163`；截断标记 `ToolResultLimiter.java:34`（`\n…[结果已截断：仅前 N 行/字符`）。刷新后 `history` 的 `toolResponses.responseData` 取自模型侧记忆 ⇒ 看到的就是这一份。
- **单帧 64KB（实时+归档）**：`backend/.../ai/run/FrameSizeLimiter.java:36,74-104` 对 `text`/`result` 做字段级截断并挂 `truncated`/`truncatedReason`，上限 `AiProperties.java:352`。

**省略号/展开按钮**：无前端省略号、**无展开按钮**；`frontend/src` 搜 `truncated` **0 命中**（标记不被消费，截断看起来像完整内容）。渲染只是固定高滚动框 `AiPanel.vue:208`、`AiPanel.vue:294`（`max-h-24 overflow-y-auto`）。

**修法方向**：消费 `truncated/truncatedReason` 出"已截断"角标 + 全文展开入口；历史侧改为存/回全文。

### Q3 多个工具调用折叠且默认折叠

- **折叠组件位置**：活动组外壳 `AiPanel.vue:171-184`（`data-activity-group`、`data-testid="block-toggle-<id>"`），组头文案"工具活动 · N 段" `frontend/src/utils/blocks.ts:78-81`。
- **形态（单卡 vs 分组）**：组成员数 = 1 时 `bare=true` 不套壳、直渲工具卡 `blocks.ts:105` + `AiPanel.vue:261-334`；≥2 段即套折叠壳。
- **默认值**：`defaultExpandedOf` 四档短路 `blocks.ts:48-60` —— requiresAction→展开、有 reason→展开、存在 pending/running→展开，**其余 false**；故一批全部终态、无失败原因的工具调用默认为折叠。用户触碰态存 store `frontend/src/stores/ai.ts:463,2017-2019`，合成口径 `blocks.ts:67-75`。

**修法方向**：把"全部成功且段数≥2"的档位也纳入默认展开（或按消息内首次工具调用展开、其余跟随后续）。
