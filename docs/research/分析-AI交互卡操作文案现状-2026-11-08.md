## 9. 输入组件光环被裁切的静态分析

### 高可能性位置：生成式表单字段滚动区

`frontend/src/components/AiPanel/FormRenderer.vue:7`：

- 字段区：`max-h-[min(320px,45vh)] overflow-y-auto`。
- 可编辑时只有 `pr-[4px]`，左、上、下没有对应留白。

聚焦外扩：

- 普通文本、数字、日期、枚举：`ring-2 + ring-offset-1`，约外扩 3px，见 `:366`。
- boolean：`ring-2 + ring-offset-2`，约外扩 4px，见 `:84`。
- 高级条件和附件删除：`outline-2 + outline-offset-2`，约外扩 4px，见 `:16`、`:180`。

因此左缘、首字段上缘和末字段下缘的光环可能被滚动视口轻微截断；`overflow-y-auto` 也可能使另一轴形成裁剪区域。这与用户描述吻合，但未做浏览器实测，不能扩大为所有浏览器、所有控件必现。

外层消息气泡与业务卡壳另有 `overflow-hidden`（`AiPanel.vue:363`、`:3968`），可能形成第二层边界；当前最直接的缺口仍是 FormRenderer 自身滚动区留白不足。

主消息输入框不是同一证据：composer 周围已有约 14px 留白，shell 自身没有 `overflow-hidden`，不能直接归因于页面侧栏裁切。

这些 ring/outline 样式由 `560fbea0` 引入，早于 `4123de2b`；不是本轮按钮文案提交新引入的样式。

## 10. Modern Web Guidance 参考

本次检索并读取了 `accessibility`、`forms`、`overflow-clipping-control`：

- `accessibility` 要求优先使用 `:focus-visible`，不要无替代地关闭原生焦点指示；推荐 outline 与 outline-offset，并检查焦点指示对比度。
- `forms` 强调标签、可见焦点和实际设备/键盘验证，不能只靠自动化分数。
- `overflow-clipping-control` 说明阴影可在父容器边界被截断；`overflow: clip` 与 `overflow-clip-margin` 可扩展裁切边界，但该属性当前并非 Chrome/Edge/Safari 全支持，且 `clip` 禁止滚动，不能直接用于本表单的滚动区。后续若施工，应优先考虑现有留白/焦点样式，并保留滚动行为和高对比度回退。

## 12. 用户最新确认的简洁操作文案基线

### 12.1 核心原则

危险信息放在卡片或弹窗正文，确认机制负责防误触，按钮只表达简单动作。不得把业务对象、数量、后果、保留结果和完整句子全部塞入按钮，避免“批准 xxx”式过度设计，以及文案、翻译和动态参数维护成本。

| 交互类型 | 目标操作文案 | 适用边界 |
|---|---|---|
| HITL 确认卡 | **拒绝 / 批准** | 不使用“批准创建任务”“批准启动导出作业”“不执行” |
| HITL 询问卡 | **取消 / 提交** | 用于需要用户补充信息的场景 |
| 多步骤询问卡 | **取消 / 上一步 / 下一步 / 提交** | 仅真实多步骤时显示步骤按钮，最后一步提交 |
| 生成式表单 | **取消 / 提交** | 当前实现已经符合 |
| 表格等结果预览 | **取消 / 应用** | 数量、范围放在卡片正文 |
| 一般确认弹窗 | **取消 / 确认** | 风险和后果写正文 |
| 特别危险或不可逆操作 | 对应简单按钮 + **确认复选框** | 只在明确高风险时显示，不得泛化到所有操作 |

### 12.2 其他应收敛的结果型文案

- “应用 {cells} 格改动”恢复为“应用”，“保留当前表格”恢复为“取消”；数量在正文表达。
- “不再上传”按场景统一为“取消”，不另造同义词。
- “保留当前对话”作为弹窗取消操作时恢复为“取消”；执行新建的危险程度由正文和必要确认表达。
- “取消作业 #{jobId}”“删除任务「{title}」”去掉按钮中的 ID 和标题，业务对象在正文展示。
- “丢弃未保存编辑并上传/切换任务/取消勾选/离开”不再把完整后果塞进按钮。
- “发布并替换范围内旧数据”把替换风险放在正文和复选框，不使用整句按钮。
- 清除 API Key、停用端点、删除模型等按钮不再拼接完整对象句。
- “保留作业继续运行/保留任务/保留编辑并返回/保留旧数据并返回/保留当前配置”按真实动作统一为“取消”或“返回”，不维护多组近义出口。

### 12.3 不得一刀切缩短的例外

- **取消作业**与**删除任务**语义不同，不能统一成同一个词。
- **开始导出、启动预检查、启动导入、确认发布**是明确业务动作，不应包装为“批准……”。
- **增量合并、范围内替换**是模式选项，不是确认按钮，应保留。
- “继续/重试/重新载入/重试恢复/立即重试”存在近义泛滥，后续按真实动作统一，不能只改名字。

以上是最新用户裁决的目标口径，优先级高于此前 D11/D12/D13 中“批准具体动作”和结果型长按钮的项目决定；实施时应在相关决策文档中追加 supersede 关系，不静默改写历史记录。
