## 2. 关键实现点

### 2.1 AI Runtime（Spring AI 1.1.8 高层 API 全程使用）
- `OpenAiChatModel` 由 `spring-ai-starter-model-openai` 自动配置（base-url=api.deepseek.com、completions-path=/chat/completions、model=deepseek-flash、`parallel-tool-calls=false`、`extra-body.thinking.type=disabled` 关闭思考模式）。
- `ChatClient.builder(model).defaultAdvisors(MessageChatMemoryAdvisor...).build()`：记忆读写全自动，`ChatMemory.CONVERSATION_ID=sessionId` 隔离页签会话，窗口 30 条，不持久化。
- 工具 = `@Tool` 注解方法（三组 Bean），每轮按活动任务类型拼装 `.tools(basic[, export|import])` + `.toolContext(Map.of("sessionId", ...))`；模型不知道 sessionId 的存在。
- 流式：`.stream().chatResponse()` 逐 chunk 取 `getOutput().getText()` 发 SSE `token` 事件；工具调用由 OpenAiChatModel 内部 ToolCallingManager 自动循环执行。
- 实验依据（开发前 curl 验证）：deepseek-flash 回放含 tool_calls 的 assistant 历史（无 reasoning_content）返回 200；`thinking:disabled` 被接受。

### 2.2 状态联动（解耦）
- 单一事实源：TaskService（状态机+守卫）→ REST 与 AI 工具都调它。
- EventPublisher：任何变更后向会话发 SSE（state=任务快照 / progress=操作进度 / activity=AI操作卡片）；无监听者静默丢弃。
- 前端 Pinia `taskStore.applyTaskMap` 统一消费 REST 响应与 SSE 事件；工作区与对话栏都是订阅者。
- 刷新恢复：`GET /api/session/state` 返回会话绑定任务 → 自动导航；`GET /api/ai/history` 从 ChatMemory 还原对话。
- 移除任一方不受影响：AI 工具与 REST 无相互依赖；SSE 无订阅者时业务照常。

### 2.3 任务状态机
- 步骤守卫集中在 TaskService（assertStep/assertSelection/assertNotTerminal...），REST 与工具共用。
- 导入数据 = `task.params.uploads`（JSON CLOB，前端 ExcelIO 解析后提交的结构化行）。
- 暂存/发布：`CONFIG_DATA.status=STAGED(task_id)` → 发布事务内"删同范围 PUBLISHED + STAGED 升级 PUBLISHED(task_id 置空)"。全局配置替换全表，地区/项目配置按 scope_value 范围替换。
- 依赖：`CONFIG_DEF.depends_on` JSON；校验（上传∪已发布业务键）与导入/发布拓扑排序都在 ImportRunner。

### 2.4 前端 Excel 全链路（SpreadJS ExcelIO + JSZip）
- 动态渲染：表头写视口第 0 行（ExcelIO 不导出 colHeader 区的坑）+ 冻结首行 + 必填列高亮 + 整列校验（ENUM/SCOPE 下拉、INT/DECIMAL 数值、DATE 日期、BOOL 公式列表）。
- 解析：excelIO.open → 隐藏离线 Workbook → 表头归一化匹配（trim/去`*`/忽略大小写）→ 类型转换 → readRows。
- 模板：buildTemplate(fields, [sampleRow]) → excelIO.save → 单个 xlsx / JSZip 打包。
- 下载：SpreadJS 实例 toJSON → excelIO.save（保留用户在线编辑）→ 单文件直接下载 / JSZip 打包。
- 上传匹配：文件名（去扩展名）= 配置项编码；zip 前端解包后逐个匹配；未匹配列表明确报错。
- LicenseKey 经 `VITE_SPREADJS_KEY` 注入；评估模式仅水印（截图中可见），功能完整。

### 2.5 Windows 环境适配
- 构建脚本 `scripts/build.mjs` 将 TMP/TEMP 指向项目内 `.tmp-build`（防杀毒锁 esbuild 临时文件）。
- Maven 用项目级 `maven-settings.xml`（阿里云镜像 + spring 源站排除），构建命令 `mvn -s maven-settings.xml`。
- 前后端启动前 `netstat -ano` 检测端口占用（本机 8080/8081/8090/5173/5174/5271 等已被其他服务占用，选用 18290/15271）。

## 3. 与设计文档的差异记录

| 设计 | 实现 | 原因 |
|---|---|---|
| ProgressManager 集中管理导出 | 导出进度由 ExportRunner 直发（ProgressManager 仅互斥/取消/耗时模拟） | 简化事件通路，行为等价 |
| 工具上下文经 ToolContext 注入 | 同左（设计阶段曾考虑 sessionId 作为工具参数，已否决） | 模型不可知会话标识更安全 |
| 无 | AiChatService 增加"同会话互斥"与友好错误映射（401/429/多工具调用） | 健壮性 |

## 4. 已知限制
- SpreadJS 评估模式水印（正式使用需授权）。
- 对话记忆为单机内存（服务重启清空，符合需求"不持久化"）。
- 单用户演示定位：无鉴权、无限流（错误分类与重试提示已具备）。
