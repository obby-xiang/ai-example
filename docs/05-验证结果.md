## 4. 验证中发现并修复的问题（过程记录）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | DeepSeek 400 | 工具 JSON Schema 中属性级 `required:true` 泄漏（DeepSeek 严格校验，required 必须是数组） | Schemas.obj() 剥离内部标记 |
| 2 | 推理内容回传 400 风险 | DeepSeek 禁止请求携带 reasoning_content | Agent 循环回填 assistant 消息时置空（实测仅前端流式展示） |
| 3 | 导出文件数据列为空 | queryRows 返回信封行（data 嵌套），buildExport 期望扁平行 | ExportService 显式扁平化 |
| 4 | 依赖拓扑排序报“循环依赖” | Kahn 入度方向写反（应为 X 依赖 D → indeg[X]++） | ConfigDefService 修正 |
| 5 | 发布后仍有草稿 | 旧生效数据置 published=false 与“草稿=未发布”语义冲突 | 发布改为**删除**旧生效数据（单一生效版本） |
| 6 | 后端 JsonNode→CharSequence 强转崩溃 | 编译期与运行期 Jackson 的 JsonNode 接口层次不一致（StringBuilder.append 重载决议） | 显式 .toString()（4 处） |
| 7 | 前端任务 id=undefined（/tasks/undefined/events） | 快照 id 位于 detail 内，前端按顶层 id 读取 | 前端归一化 {…snap, id: snap.detail.id} |
| 8 | SpreadJS 打开失败（FileReader 报非 Blob） | ExcelIO 17.x 使用 JSON 协议：open(file,ok,err)+fromJSON / save(json,ok,err)，且需 File 类型 | SpreadSheet.vue 改用该 API |
| 9 | AI ui_event 驱动工作区失败 | 多键事件被拆成两个独立事件（task/defCodes 分离），前端误路由 | 工具端合并为单事件 |
| 10 | 确认续跑吞掉新确认卡 | confirmTool 的 finally 无条件清空 confirm，覆盖流中新到的第二张卡 | 改为流开始前清空，新卡由 ui_event 处理器挂载 |
| 11 | get_batch_status 工具失败 | detail.files 元素是 POJO 被当作 Map 读取 | instanceof 判断 + convertValue 兜底 |
| 12 | 脚本兼容 Windows PowerShell 5.1 | UTF-8 无 BOM 被按 ANSI 解析；byte[] 构造器被展开；HttpClient 程序集未加载 | BOM/参数打包/Add-Type |
| 13 | xlsx 篡改构造非法数据失败 | 原地 Update zip 破坏 OOXML 包结构 | 全条目重建 zip |
