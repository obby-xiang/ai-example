## 阅读顺序建议

1. **第一次接触项目**：仓库根 `README.md`（跑起来）→ 本页 → `docs/02-需求设计文档-v2.2-冻结版.md` §1（要做什么）。
2. **要动某个机制**：先查 `docs/adr/DECISION-REGISTER.md` 是否有生效决策，再读对应 ADR 卡，最后看 `docs/s4/` 规格与 `docs/evidence/` 证据。
3. **要新增/变更决策**：走"证据文档 → 决策卡 → 登记表"三步，并在 `docs/M2-排期计划.md` 挂批次条目。
