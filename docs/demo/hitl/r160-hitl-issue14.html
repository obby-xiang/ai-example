issue #14 HITL 组件刷新后不渲染 + 决策元数据丢失 + 文本溢出 · 方案 demo

四个场景：A 确认门完成后刷新 ｜ B 生成式表单提交后刷新 ｜ C 确认门 pending 中刷新（倒计时恢复，本 demo 新增口径）｜ D 文本/组件溢出。每场景先播「交互过程」，点「模拟刷新 F5」对比刷新后差异。
模式：
修复口径（本 demo 提案）： ①回执卡移出工具卡折叠体，提升为消息内独立块（NN/G 渐进式披露：折叠体内不嵌套关键回执）——运行中 pending = 可编辑+默认展开；完成 = 只读+默认折叠为一行摘要（标签+时间戳+参数），点击展开详情； ②决策元数据 decision / decidedAt / submittedValues 后端持久化（toolCallStates 载荷 {status,kind} → 扩三字段 + 白名单透传），loadHistory 重建时恢复——刷新后徽标/时间戳/已提交值全保留； ③kind2 双保险：后端补 kind + 前端判据加 name 兜底，缺项不再降级 UNKNOWN 致整卡消失； ④溢出：气泡加 overflow-hidden、表格/JSON 块 overflow-x-auto 横向滚动、表单组件 max-width:100%。
遗漏点（issue 未覆盖，本 demo 补充）： Ⓐpending 门刷新恢复：倒计时按服务端 expiresAt 剩余秒继续，不重置不丢失（场景 C）； ⒷAiController 透传字段白名单需同步扩三字段（否则后端存了也到不了前端）； ⒸCollapsibleText 的 ResizeObserver 缺失环境恒不展开（无「显示更多」兜底）一并修； Ⓕargs 区 break-all 与 CollapsibleText 无换行控制的两处口径不统一，一并收敛。
