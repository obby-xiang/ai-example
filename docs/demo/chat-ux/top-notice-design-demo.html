    #场景顶部说明
    01正常无顶部提示—普通对话，不产生通知。
    02AI 整体不可用一条强提示唯一全局出口，提供「重试」；不展示技术原因。
    03自动恢复中静默—只有消息内「工作中…」与停止钮，不提示正在恢复。
    04自动恢复失败一条恢复提示内容可能不完整，提供「重新载入」作为手动恢复。
    05多故障最多一条整体不可用两类故障同时存在时只显示整体不可用，不并列、不排队。
    06提示清理消失恢复正常、换会话或开始新轮后立即清理。

    目标原则：顶部最多一条，只有「AI 暂时不可用」与「自动恢复失败且内容可能不完整」。 自动恢复中、自动重试与技术原因保持静默。
    Demo 说明：场景、外壳按钮与映射表均为展示用途；输入、顶部动作、发送与停止均为纯前端模拟，不连接后端。
