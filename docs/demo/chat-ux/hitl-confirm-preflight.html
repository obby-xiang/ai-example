主题与口径

场景一 / 二 / 三 同页纵向排布

主题 = H1 确认卡 + 预检摘要（F5 预检前移，用户 2026-10-20「demo通过」定稿）。口径：按钮 = 「拒绝 / 批准」；预检摘要区为本轮新增，位置在参数行与按钮行之间；预检不通过 → 不进确认门、不弹卡（2026-10-20 用户直裁）：结构化失败回给模型，由 AI 用普通消息说明原因与建议，此时不存在「批准钮禁用」的审批卡；场景三保留旧版卡面（仅操作 + 参数、无预检区）作对照。示例数据全虚构。

场景二 · 预检不通过：不弹确认卡

预检失败即不进确认门 —— 不存在「批准钮禁用」的审批卡形态；结构化失败回给模型，AI 用普通消息说明原因与建议，可折叠「预检明细」，卡面与按钮一律不出现。 ✗ 2 项未通过 无卡 · 不进确认门

助手 · 普通消息

口径：预检不通过 → 不进确认门、不弹卡（2026-10-20 用户直裁）；结构化失败回给模型，由 AI 用普通消息说明原因与建议，此处不渲染批准 / 拒绝按钮。
