配置助手

调宽

右侧停靠时拖拽面板左缘，或聚焦分隔条后按 ← →，每次 16px。默认宽度 clamp(360px, 30vw, 420px)；最小 360px；常规最大 640px；实际最大 max(360px, min(640px, 100vw - 720px))；视口足够时给左侧业务区留出至少 720px。宽度存在本机。

空间不足时业务区内部内容/表格横向滚动，面板保持右侧停靠，不覆盖业务；当前视口没有额外可调空间时，拖拽手柄自动隐藏。

新建对话

有消息或正在运行时先弹原生确认，文案明确“清空且不可恢复”，默认焦点在“取消”；空会话直接新建，不弹窗。

状态

工作中为蓝色呼吸点，等待确认为琥珀色呼吸点。运行中可停止；等待卡批准或拒绝后会继续本轮回答。

静态原型：刷新页面会重置会话；面板宽度保存在本机。空间不足时业务区内部横向滚动，面板保持右侧停靠。
