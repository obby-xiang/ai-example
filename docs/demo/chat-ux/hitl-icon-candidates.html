设计口径与取舍

  • 四款统一 24×24 viewBox、fill none、stroke currentColor、1.7 描边、圆头圆角；实际卡头内为 15×15、#57606a。
  • A/B/C 的问号字形尺度一致，只按各自外框上下平移；D 无外框，因此刻意占用更大的字形高度，15px 下笔画最清楚。
  • B 的气泡尾巴在左下，问号整体上移；C 的气泡更方、尾巴更含蓄；两者在 15px 下仍保留可辨轮廓。
  • 四款都不承载状态：图标始终中性，右侧状态标签才是唯一状态语义；本页不推荐某一款，等待用户看图选择。
