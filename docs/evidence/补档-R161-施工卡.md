## 施工面（七项）

1. **统一 `pinBottom()`**：设 `scrollTop=scrollHeight` + 记落点 `pinGuardTop` + 置 `followBottom=true`；既有 `scrollBottom`（`AiPanel.vue:741-752`）、send force（`:894/:906/:912`）、`backToBottom`（`:502-505`）全部改走它。
2. **回声闸**：`onMsgScroll`（`:491-497`）加回声判定——`|scrollTop − pinGuardTop| ≤ 1px` ⇒ 只更新 UI 态、不动 followBottom（容差判据，会审 M1）。
3. **RO 内容重钉底**：`ResizeObserver` 观察 `msgWrapRef`（`:118`），回调 = scrollHeight 增大且 followBottom=true ⇒ `pinBottom()`；`onBeforeUnmount` disconnect（照 `:1081-1084` 体例）。
4. **撤 `:1052` setTimeout hack**：expanded watch 保留但改调 `pinBottom()`（RO 不覆盖「容器自身尺寸变」之外的时序时兜底）；指纹 watch `:1041-1050` **保留不动**（会审 M5 裁决：幂等无害）。
5. **阈值拆分**：`FOLLOW_THRESHOLD_PX=32` 保留；新增 `SHOW_BACK_TO_BOTTOM_PX=64` / `HIDE_BACK_TO_BOTTOM_PX=24` 滞回；`showBackToBottom`（`:499`）改独立带滞回状态（非 `!followBottom` 纯计算），onScroll 驱动显隐；`backToBottom` 显式置 false（会审 M3）。
6. **平滑回底**：浮钮点击 = 加 CSS `scroll-behavior:smooth` 类 + `pinBottom()`，约 600ms 后移除类（demo 口径）；**禁 `scrollTo({behavior:'smooth'})`**（会审 M2：保 jsdom 同步断言）；流式期 pinBottom 恒瞬跳。
7. **`role="log"`** 补 `:118` 滚动容器。
8. **呼吸动画豁免 reduced-motion**（用户实测回归，根因已定位）：`:1237-1246` `@media(prefers-reduced-motion:reduce)` 块把 `.loading-breath .dot/.txt` 移出 `animation:none` 抑制（呼吸=状态语义非纯装饰，豁免；`.caret` 抑制保留）；豁免后 reduced-motion 环境下呼吸照常 1.4s 律动。spec 增 1 例：reduced-motion 下呼吸节点 animation 不为 none（jsdom 可取计算样式或断言 media 块选择器不再含 loading-breath）。
