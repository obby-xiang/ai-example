## 7. 与 demo 的口径偏差登记（需指挥官知悉）

1. **卡头图标钮的 tip 翻到钮下方**（§2 项 5）：demo 卡壳 `overflow-hidden`，卡头钮的「上方气泡」会被裁掉（demo 自身同形，
   其卡头钮 tip 实际不可见）。为保证「图标钮 = aria-label + tip」口径**真的可见**，卡头两钮改用下方锚点；
   其余钮仍照搬上方锚点。改动面 = 两个常量（`MMD_TIP_BELOW_CLASS` / `MMD_TIP_ARROW_BELOW_CLASS`）。
2. **源码盒用 `div`（非 demo 的 `pre`）**：preflight 关闭 + `.ai-chat .md-body pre`(0,2,1) 双重约束下，用 `pre` 需要 5 个 `!` 覆盖；
   改 `div.whitespace-pre` 后零 `!`、零特异度冲突，box 行为等价（内容走 `textContent`）。
3. **mermaid 卡名固定「流程图」**：demo 卡头显示图名（它的图有名字），本仓 mermaid 产物无图名可读 ⇒ 沿用既有文案；
   `mlib`「mermaid」小标随旧卡头一起退役（dem v7.7 卡头已无此标）。
4. **查看器叠加层留在面板内（未 Teleport 到 body）**：实测祖先链无 `transform/filter/will-change` ⇒ 不形成 containing block，
   `position: fixed` 相对视口、`z-[70]` 全局生效（截图 `s5b-inj-06-viewer-open.png` 覆盖全屏）；若后续给祖先加 transform，需改 Teleport。
5. **降级态（render 失败）改为「源码态卡」**：旧实现在失败时把卡展开源码（`is-open`）；新结构下改为不渲染 tab / 读数 / 复位 / 全屏的源码态卡
   （源码直显 + 复制可用），保证「不留无 handler 的钮」。
6. **`markdown.ts` 的 1 行注释**：原文「（= 失败兜底与「查看源码」同体）」在「查看源码」钮退役后已失效，改为
   「（= 渲染失败时的兜底源码；…卡内「源码」态展示同一份源码）」。**逻辑零改动**（`git diff markdown.ts` 仅注释行）。
7. **`preview` 的滚轮被缩放独占**（demo 同口径）：预览容器是 `overflow-auto`，但 wheel 走 `preventDefault` + 缩放 ⇒ 纵向浏览靠**滚动条或拖拽平移**，
   横滚照旧。这是「滚轮缩放」与「超宽横滚保留」两条口径的直接结果，非回归。
