### 4.2 🔴 长不可断 token 撑破 `md-body` 后被气泡 `overflow:hidden` 静默裁切

链条（全部真实复现，非注入）：
1. 用户气泡/助手气泡容器 = `min-w-0 overflow-hidden w-full px-2.5 py-2`（`AiPanel.vue:171`；注释 R-160 M4「一刀切」）。
2. `.md-body` 根容器**已无** `word-break/overflow-wrap`（`ai-chat.css:94-98` 注释 D1：为消除长英文标识符被任意断开的元凶而撤掉）。
3. 行内 code 保留 `white-space: nowrap`（`ai-chat.css:128-136`）⇒ 长 token 不可断。

实测：`run-clip2.mjs` 发「启动导出作业」后，M4 助手气泡 `scrollWidth=584 / clientWidth=372`，**212px 内容被裁掉**；元凶元素 = `<code>`（`white-space: nowrap`，宽 555px，内容 `Failed to fetch dynamically imported module: …/views/ExportWizardView.vue`，overhang **+222px**）。裸 URL 段落（`<a>`，`overflow-wrap: normal`）仅溢出 12px、被裁 2px——浏览器在 `/`、`?`、`&` 处可断，故不严重。

视觉证据：`real-27-M4-clip-audit.png`（提示条与气泡正文在面板右缘被硬切、无省略号无滚动条）、`real-26-M4-R1-clipped.png`。

> 口径提示：demo 的 `.md .ic{white-space:nowrap}` 与 demo `.panel{overflow:hidden}` **同样存在**，属 demo 与真实的**共同潜在弱点**，只是 demo 静态页无此场景故未暴露——不算「移植偏差」，但真实内容会稳定触发。

### 4.3 🔴 mermaid 卡壳渲染但 SVG 缺失 —— vite optimize-deps 504（**未触发**场景）
