# 二、时间链：热/冷分工如何一步步变成"没有入口"

1. **10-11~10-12：单体全量档**。每份都自带全部纪律（存档纪律、分工、工作方式、环境凭证），且写明"旧档全文继承、不删不改"。风险=档体膨胀（88KB）。
2. **10-12~10-13：分层**。当前态档 + 附录档 → 再拆热档（§H0~§H6）+ 冷档（永冻 90KB）。**这一步本身是用户直裁的（热档 §H2:20 "态档热冷分离=用户直裁做，销项"）**，不是丢失。
3. **10-13~10-21：每棒稿 = 指针 + 增量**。每棒稿开头都写"读热档全文、§H4 纪律全集以热档为准"，纪律本体留在热档，**这是委托（D），不是丢失**。
4. **10-22 重构**。改成短当前态（65 行），第 59 行把热档写成"**更老历史…仅作考古**"。这是**第一次把热档从"唯一基线/必读"降级为"考古"**，而热档 §H1 仍自称"唯一基线"——两份同时在库、口径互斥，且热档未标注废止。
5. **10-24**。只在第 16 行把热档当**密钥存储**（"真 key 值在第 143 行"），其余不再引用。
6. **10-26 STATUS**。全文**不出现 handoff-archive、不出现热档/冷档**，自成一体。至此 37 份交接对"新会话"不可达。
