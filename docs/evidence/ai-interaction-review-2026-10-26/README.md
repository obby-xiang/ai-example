### 6.1 重复内容（按**可复现**哈希登记，不重复入库）

**哈希口径（30 份统一，可按此复现 §3 表内数值）**：

1. **取源文本**：`.log` 源件按 UTF-8 解码并**剔除 BOM**（30 份源件实测：**均无 BOM、EOL 均为 LF**）；`wire` 提取件取其消息 `content` 中全部 `text` 段，以 `\n` 连接成一段字符串。
2. **不做任何空白归一、不做任何脱敏替换**（哈希对应“源文本原样”，**不等于**本目录归档件正文的哈希）。
3. 对该文本取 **SHA-256**，取**前 16 位小写十六进制**。

复算示例（`.log` 源件，直接可跑）：

```bash
python -c "import hashlib,sys;print(hashlib.sha256(open(sys.argv[1],'rb').read().decode('utf-8-sig').encode()).hexdigest()[:16])" <源件路径>
```
