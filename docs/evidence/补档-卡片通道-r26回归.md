## 1.5 浏览器步骤（可复跑）

1. 内置浏览器新开 `http://localhost:5202/` → 自动进入 `/tasks`，会话 `<SESSION_ID>`。
2. 点快捷动作「查看当前工作区状态」→ 回填输入框 → Enter；等 4s，得 tool 已成功卡；再发「请列出全部配置定义」。
3. 发「请用 generative_form 生成…」→ 待填 GF（`变更单补充 / 1 项必填 / 待填写`）；填 `SECRET-R26-CANCEL` 后点「取消」→ 已取消卡；点卡头展开，回读两个 input 空且 disabled、无提交按钮。
4. 再发同表单（标题 `变更单补充-提交轮`）→ 填 `CHG-2026-R26 / 提交轮备注` → 点「提交」→ 已提交卡（摘要回显）。
5. 发「请对任务 #297 启动导出作业」→ AI 打开 #297 向导；勾选全选、下一步×2 到「导出执行」；发「当前工作区就是…请直接调用 start_export」→ 待决 HITL「启动导出作业（任务 #297）等待确认」；点「拒绝」→ 已拒绝。
6. 再发 start_export → 待决 → 点「确认执行」→ 已批准（真实启动作业 #353，后 1600/1600 完成）。
7. 发「请下载任务 #297 的导出文件」→ 下载失败 tool 卡（调用当次）。
8. 再发 start_export 且不处理 → 240s 实时超时先显示「✗ 已拒绝」；整页 reload → 「! 已超时」折叠（同时复现 failed 卡变「已成功」的既有缺陷）。
9. 辅助量测（仅几何）：新 Chromium 1280×800，重复 tool/GF（400、360、取消、accessible name）；另开 `/export?taskId=296` 全选→下一步×2→start_export→待决门卡 400/360→拒绝。
