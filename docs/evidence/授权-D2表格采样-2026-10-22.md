```text

```

- 与 8/9 个表格工具的 `@ToolScope` 注解**逐字相同**（`backend/.../ai/tools/AiTools.java` 的
  `@ToolScope({ "task:EXPORT/EXPORT", "task:IMPORT/UPLOAD" })`），并与前端
  `frontend/src/types/tools.ts` 的 `SHEET_SCOPE_PATTERNS` 同值 —— **三处比对**，多一个页面即越权。
- 授权通道（**全部**是 D2 通道，读侧与写侧一并覆盖）：

```text
授权通道 : read_sheet_summary   （投影采样行，≤20 行 / ≤2000 字符）
           find_rows            （命中行号 + ≤20 行采样，命中单元格带地址）
           review_cells         （校验明细 ≤20 条，明细含单元格原文）
           aggregate_sheet      （聚合值，非行；分组标签是业务值但不成行）
           inspect_columns      （列名与映射建议，0 行业务值）
           replace_values / update_rows / normalize_column(commit=true)
                                （写侧 ≤3 处「旧值 → 新值」样例随结果回灌）
           undo_last_sheet_edit （回执只报格数与 planId，不含单元格值）
排除通道 : 任何"整表 / 整 defCode 全量"读取；任何服务端转存；任何落库
```

> 与代码一致的边界（2026-10-22 复核）：`inspect_columns` 与 `aggregate_sheet` 的 `dataClass`
> 记 `D1`（无采样行）；其余读工具在有采样时记 `D2`。D1/D2 的分级字段随 `tool_call_end` 落日志
> （`SheetAudit.LOG_FIELDS`），**不含任何值**。

## F5 projection（投影规则）

```text
maxColumns         : 5
allowedFieldKinds  : 全部字段类型（不做类型排除；采样值一律按显示文本回灌）
defaultScope       : selection  （未指定 scope 时只读用户选区，不读整表）
requiredDisclosure : true       （回灌文本必须显式写出"采样 N 行 / 共 M 行"，
                                 即用户与模型都能看见"这不是全量"）
selectionColumns   : 不设列上限（取值范围 = 用户框选的实际列数，不受 maxColumns ≤ 5 约束）
```

**授权范围说明（选区不收窄，2026-10-22 裁决）**：**用户显式框选即逐次授权**（业界同姿态 = Gemini
按 tab / 区域勾选、Airtable 显式字段引用），故选区路径的列面不收敛到 5 列；但行数（F3 ≤ 20）与
字符数（F4 ≤ 2000）两道硬闸对选区**同样生效**，且回灌文本必须如实写出"选区 N 列"，不得让用户
误以为只读了 5 列。

> 落地对照（代码事实）：`projectedColumns()` 的选区分支**不加** `slice(0, 5)`；`columnCodes` 与
> 缺省投影两条路径的上界 = `min(硬顶 5, app.ai.sheet.projection-max-columns)`，越界为**具名拒绝**
> （不静默截断 —— 静默截断会让"列 A 没读到"被误读成"列 A 不存在"）。
