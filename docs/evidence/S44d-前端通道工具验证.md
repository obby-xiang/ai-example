## 4 V4 幂等与兜底

### 4.1 同 `toolCallId` 重复回灌 → 拒绝（HTTP 409）

轮次（`runId=a2ee10bc-…`，上下文 `page:definitions`，消息"请把界面切到数据浏览页"）挂起在
`frontend_tool_request name=navigate_to args={"page": "data"}` 后，对同一 `toolCallId` 连发两次回灌：

```
第一次 HTTP 200 {"accepted":true,"duplicate":false,"status":"FRONTEND_RESULT","wokeInProcessGate":true,…}
第二次 HTTP 409 {"code":"DUPLICATE_TOOL_CALL_ID","message":"该 toolCallId 已有决策或结果，重复提交被拒绝",
                 "status":"FRONTEND_RESULT","duplicate":true,"instanceId":"instance-…"}
```

随后该轮正常继续并以 `done`（usage 2445/133）收尾 —— 幂等拒绝**不影响**在途轮次。
原文：`<EV>/S44d-附件-F-V4a-重复回灌请求响应原文.json`、`<EV>/S44d-附件-E-V4a-幂等轮-SSE原文.sse`
（挂起期帧：`frontend_tool_request` → `heartbeat ×50`（waitedSeconds 2/4/…/98）→ 结果回灌 → delta → done）。
说明：本项为**协议层直呼**（无浏览器进程）验证幂等语义；下述 4.2 为真实浏览器轮次。
