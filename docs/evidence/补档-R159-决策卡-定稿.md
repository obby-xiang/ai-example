## 一、方案（demo 定稿口径，六项）

1. **光标 B1 粗块**：8px×1em、`#303133`、圆角 2px、闪烁 `caretBlink 1s steps(1)`（0–55% 显）；替换现状 2px `#409eff` 细线。落点 `AiPanel.vue:1121-1129`。
2. **「工作中…」全程常驻**：发出即现（demo 为 300ms 微延迟）；首字符上屏不消失（修 isTyping 首字符即翻）；**单一元信息行**左位 = 流式期「工作中…」呼吸 / 完成后时间戳。
3. **流式期无时间戳无复制**：元行右位复制 `visibility:hidden`；完成时换入（hover 浮出可点）。
4. **完成优雅淡出**：光标+「工作中…」同帧淡出 300ms（`caretOut .3s ease forwards`）→ 元行换时间戳（左）+复制（右）；现状为即时硬消无过渡，本项为**新增**淡出（非「废拖尾」）。
5. **工具卡升级（demo 版）**：齿轮图标 `#409EFF` + 「前端工具」plain etag + 执行中 = 深绿实心（`#67c23a` 底白字）/ 已完成 = 浅绿（`#f0f9eb` 底 `#67c23a` 字）；**工具执行期正文光标收起**，执行完归位。
6. **新字符渐显**：增量文本包 `span.ch`（`chIn .18s ease-out`，opacity .1→1），替代整块硬跳。
