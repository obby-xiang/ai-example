### 项 5：长表格双区结构（v7.6/v7.7 修法）

渲染层 `markdown.ts` `wrapTables()`：`<table>` → 三区结构（**`md-table-scroll` 单容器方案退役**）：

```html
<div class="md-table-wrap mb-3.5 w-full overflow-hidden rounded-[8px] border border-solid border-[#eef0f3]">
  <div class="md-table-hd overflow-hidden pr-[6px] bg-[#f6f7f9]"><table class="… min-w-[720px]">…<thead>…</thead></table></div>
  <div class="md-table-bd max-h-[320px] overflow-auto [scrollbar-gutter:stable] …"><table class="…">…<tbody>…</tbody></table></div>
</div>
```

| 判据 | 实测（真机 20 行 4 列 / 注入 22 行 4 列） |
|---|---|
| 表头区不滚、无边条 | `clientW 350 / scrollW 726`、`sbV 0 / sbH 0`（v7.6 §2① 「滚动条不穿表头」的数值判据） |
| 表体区限高内滚 | 真机 20×4：`maxH 320 / clientH 320 / scrollH 890`；注入 22×4：`scrollH 1340`；竖条占位 **6px**（headed）、`scrollbar-gutter: stable` |
| 竖滚动条只属表体区 | headed：表体 `barW 6 / barH 6`、右缘 `x 1414`；表头 `barV 0 / barH 0`、右缘同为 `1414`；截图中滑块起点在表头下缘之下 |
| 列对齐 | 两表 `table-layout: fixed`、宽同为 **720px**（`border-separate / border-spacing 0px`）；4 列左缘 `1064/1244/1424/1604` **逐列 maxDiff 0.00px** |
| 横滚联动 | 量程 `376`（720−344）；`bd.scrollLeft=60 → hd.scrollLeft=60`；`=90 → 90`；表头区量程同为 376（726−350），与表体逐像素同步 |
| 竖滚不带动表头 | `bd.scrollTop=150 → hd.scrollTop 0`、`th.getBoundingClientRect().top` 不变（Δ 0.00） |
| DOMPurify | `div` 三区标记类放行（`RENDER_MARKER_CLASSES`），随行 Tailwind 工具类**整条保留**（旧 hook 会剥掉）；渲染层断言同步改写 |
| 窄表边界 | 2 列表不给最小宽度（`min-w-[` 零命中）、不触发横滚；表体不超 320px 时无滚动条 ⇒ 与现状视觉一致 |

**列宽下限（本批唯一自定规则，锚点 = demo）**：demo v7.6/v7.7 的 4 列窄表写 `min-w-[720px]` ⇒ **180px/列**是终审通过的
可读下限。本仓渲染层列数不定，故按列数取**静态档位**（3→540、4→720、5→900 … 10→1800，>10 取最大档），
`≤2 列不给最小宽度`。**为什么必须给**：`w-full table-fixed` 下表格宽度恒等容器宽 ⇒ 永不横向溢出，
「横滚联动」会退化成死代码；给 180px/列后横滚才真成立（真机实测量程 376px）。
档位表用字面类名（JIT 只能扫静态类名，禁运行期拼类名 —— 同 `CollapsibleText` 既有先例）。
