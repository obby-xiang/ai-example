## 4. 结论

- 三类型卡头的结构回落（tool 扳手 / HITL 盾牌 / GF 清单）、右状态唯一承载、36.39px 卡头、15px 中性图标、chevron 最右、360/400 面板无内部横向溢出、按钮防折行、限高内滚、GF 一卡一头与取消空值：**PASS**。
- `yarn test` **409/409**、typecheck 0、build 0：**PASS**。
- **BLOCKED（均非本批新增缺陷，未改码）**：
  1. HITL「已批准 · 执行失败」真实项目 UI 仍不可达（真实执行失败仍显示已批准）；
  2. 普通 tool failed 跨刷新恢复为「已成功」（既有恢复/状态不一致）；
  3. running 与普通 tool pending/`export.start`/`import.upload` 等待卡需依赖单测佐证（真实窗口过短或当前披露不可达）；
  4. blocked/unknown 无真实入口，仅单测负控制。
- 未发现本批目标 FAIL。
