### 1.3 覆盖率算法与语料快照

- **行指纹**：每行做 `NFKC` → 空白折叠 → `trim`，丢弃长度 <6 的短行，取 `md5[:16]`。语料侧按文件建集合，并汇总全局多重计数。
- **候选覆盖率** = 候选行指纹在语料中"存在"的比例；**孪生判定** = 与单个语料文件的重合行数 / 候选去重行数 ≥ 0.85（命中即视为"已落盘等价件"，直接排除，不再按覆盖率算）。
- **语料快照**（2026-10-26 04:4x UTC 冻结）：**2,014 个文件 / 178,051 条行指纹** = 仓内 `git ls-files -co` 口径 **726 份 `.md`**（当时点，含未跟踪）+ **1,288 份可读落盘 `.md`/`.txt`**。
- **落盘路径来源**：全部 wire 的 `Write`/`Edit`/`MultiEdit` 工具调用 `args.path`（29,981 次调用、6,775 个唯一路径）+ `Bash` 命令里的 `>`/`>>`/`tee` 重定向目标（126,818 次调用、1,657 个唯一路径）。
- 已知限制：语料只收**当前仍存在且可读**的落盘文件；已删除的落盘件、`.log/.diff/.json` 运行产物不入语料；因此"覆盖率"是**下界近似**，不是"确证无等价内容"。
