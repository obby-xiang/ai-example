## 四、跨文件事实与红队观察点（供上级裁决）

1. **公开 API 收缩（编译面）**：`SseChatEmitter.replayTo(SseEmitter, boolean, Long)` → `replayTo(SseEmitter, Long)`（删 `includeDelta` 死分支）；`persistedFrameCount()` 被**删除**（当前工作树已无任何调用者，grep 确认）；`replayAndAttach` 签名未变但返回值语义由「已发出帧数」变「已入队帧数」。`RunStore.EVENT_WINDOW` 由 private 升 public。
2. **静默行为变更风险**：`SseChatEmitter` 新增的 5 参构造被 `RunRegistry` 的 `@Autowired` 3 参构造使用；`@Autowired` 只标在 3 参构造上。若某处（含 `@SpringBootTest`）改回 2 参构造，投递将**静默退化为同步直执**——T3-1 的隔离效果消失而测试仍可能绿（`SseChatEmitterDeliveryTest.twoArgRegistryAlwaysDeliversInlineAndNeverReadsTheSharedPool` 有意锚定了这个口径）。
3. **静态池是进程级单例、首装配者胜**：`configureSharedDeliveryPool` 幂等且在 `RunRegistry` 构造期调用，同 JVM 多上下文（多测试类）装配的池参数以**第一个**为准，后续配置改动不生效。
4. **心跳仍会被入队实时队列**（`emit` 的 subscribers 循环对心跳与业务帧一视同仁），因此慢订阅者的 256 容量会被心跳占用、进而更早触发溢出摘除——文档口径强调的是"心跳不占业务 seq"，不是"心跳不入队"。
5. **`EVICTED_TOTAL` 为 static 累计计数**，跨写出器共享、无重置口，health 的 `evicted` 是进程累计值而非本轮值。
6. **归档口径收窄的连带后果**：`archivedSeqs/archivedTypes` 类断言、`clientView` 归并口径、`lastEventSeq` 语义三处测试同步改写；设计卡已登记「正文尾部不可回放复原」的后果（S3-4），是否影响 T3b 前端兜底需上级确认。
7. **未验证项**：本次为纯只读导出，**未运行构建或测试**，上述所有"绿""达成"引用均来自证据文档自身陈述，非本次实测。
