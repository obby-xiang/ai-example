## 根因：**dev 代理目标端口错**（非端点路径、非判定逻辑）

链路：`frontend/.env.local:1` 写死 `VITE_API_BASE=http://localhost:18318` → `vite.config.ts` 的 `/api` proxy `target = env.VITE_API_BASE` → 指向 **18318（无任何进程监听）** → 每个 `/api/*` 在 node 层 `ECONNREFUSED` → vite 以 **HTTP 500 空体**回给浏览器 → axios 命中「`status>=500` 且无 JSON `message`」分支（`src/api/http.ts:72-74`）→ 页面提示 **「后端服务不可用或未启动（HTTP 500）」**（即你看到的「后端服务没启用」）。

- 判定来源：`src/api/http.ts:62-68`（`status===0` → 「后端不可达，请确认服务已启动（/api 代理目标见 VITE_API_BASE）」）与 `:72-74`（代理/网关 5xx 无体 → 「后端服务不可用或未启动（HTTP xxx）」）。它**没有独立健康探针**，就是普通业务端点首屏失败：日志中失败的是 `/api/tasks?page=0&size=10`、`/api/ai/health`、`/api/ai/history/<id>`。
- 后端本身健康：直连 8081 → **200**，`{"available":true,"code":"AI_AVAILABLE","model":"deepseek-flash","baseUrl":"https://api.deepseek.com"}`。
