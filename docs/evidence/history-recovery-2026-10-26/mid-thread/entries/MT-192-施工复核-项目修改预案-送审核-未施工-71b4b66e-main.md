## 项目修改预案（送审核，未施工）

核心是把项目卡片统一成：

```text
左侧固定类型图标｜标题/摘要｜右侧状态标签｜chevron
```

**只有 tool、HITL、GF 三种卡片类型；已决是状态，不再另做一种回执卡。**

### 1. `frontend/src/utils/blocks.ts`

新增两个纯函数，复用现有判据，不另造状态机：

- `cardTypeOf(part)`：
  - `kind2 === 'CONFIRM'` → `hitl`
  - `name === 'generative_form'` → `form`
  - 其他 → `tool`
- `cardStatusOf(part)`：
  - 已决卡继续走 `isReadOnlyCard / readOnlyStateOf`
  - 普通工具继续走现有运行状态
  - 统一输出 `key / label / tone`

现有折叠函数、`readOnlyDefaultExpanded`、`resolveBlockExpanded` 均不改。

### 2. `frontend/src/components/AiPanel/AiPanel.vue`

这是主要修改点：

- 将目前并列的“普通工具卡”和“已决只读卡”卡头，合并为**同一个卡头结构**，卡体仍按各自分支渲染。
- 左侧改为内联 SVG 类型图标：
  - tool：工具图标
  - HITL：盾牌/审批图标
  - GF：清单图标
- 左图标统一中性色，**跨 pending、成功、失败、批准、拒绝、取消等状态保持不变**。
- 删除原左侧状态字形、旋转环，以及“前端工具 / 确认门”等类型 chip。
- 状态标签移动到标题右侧、chevron 左侧；状态颜色只留在右标签，标题和摘要统一中性色。
- 不新增图标组件，不在项目里做 bare/tile 双皮肤或 URL 切换。
- 保留旧 testid、折叠状态管理和手动展开逻辑，降低回归面。

各类型行为：

| 类型 | 右侧状态 | 折叠规则 |
|---|---|---|
| tool | 待执行、调用中、已成功、执行失败等 | 有卡体时可折叠 |
| HITL | 等待确认、已批准、已拒绝、已超时、已批准·执行失败 | 待决不可折叠、无 chevron；已决按 r15 默认折叠 |
| GF | 待填写、已提交、已取消 | 待填写不可折叠、无 chevron；已决按 r15 默认折叠 |

其中建议把普通 tool 的“等待确认”改成 **“待执行”**，“等待确认”只留给 HITL，避免文字上再次混型。

### 3. `frontend/src/components/AiPanel/FormRenderer.vue`

- 增加可选 `showHeader` 属性，默认 `true`，保证独立使用方不变。
- AiPanel 中的待填写 GF 传入 `showHeader=false`，由外层统一卡头承担标题。
- 字段、按钮、校验、限高、原生 disabled、未提交不记录全部不动。

这样解决 GF 的**双卡头、卡中卡**，但不重写表单组件。
