## 4. 方案自决与口径登记（需指挥官知悉的 5 条）

1. **长度口径 = UTF-16 码元数**（`String.length()`），与 HTML `maxlength` / JS `String#length` 同一把尺 —— 8192 个汉字（24576 字节）放行，中文不会被 UTF-8 字节数提前判死。
2. **顺序 = 归一化 → 长度 → 限流**：量的是"真正进模型的那份"，零宽填充不吃额度；被 400 拒掉的请求不占限流配额（有专门用例锁住）。
3. **NFKC 实测边界**（已用用例钉住）：全角 ASCII 变体折半角（`，`→`,`、`（`→`(`），**中文原生标点不折**（`。` U+3002、`、` U+3001 保留），汉字/emoji 一字不动。副作用：`/history` 回读的用户消息里全角逗号/括号会变半角（1:1 映射、语义无损）。**若不接受这一类改动，需改判为排除 U+FF00–U+FFEF 的定向归一** —— 本批按指令原文用标准 NFKC。
4. **滑动窗口**（非固定窗口）：固定窗口在边界会放过 2× 额度，而本闸拦的正是脚本连发。时间取 Redis `TIME`，多实例时钟漂移不会切碎窗口。
5. **IP 维只认 `RemoteAddr`**，不读 `X-Forwarded-For`（可伪造、本仓无前置代理）；无 IP 时用固定桶 `unknown`。
