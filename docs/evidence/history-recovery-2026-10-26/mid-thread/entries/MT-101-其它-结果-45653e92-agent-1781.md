## 修复内容

### I-1：`--run-id` 空值作用域

`parseArgs` 现在对 `--run-id=`、`--run-id ,`、`--run-id= , ` 直接抛 `--run-id 缺少值`，不会静默变成全量扫描。`main` 先解析参数再读 `AI_REDIS_CLUSTER_NODES`，因此失败发生在连接/扫描前。对应测试 4 条（含 `main(['--run-id='])`）。

### I-2：删除源两阶段 + PTTL 充分性

`deleteVerifiedSources`（`scripts/redis-run-migration.mjs:810`）改为：

1. 先对全部候选做值对账 + `sourcePttl/targetPttl` 充分性检查；
2. 全部通过后才统一 `DEL`。任一失败不删任何源。

`ttlSufficient`（`:382`）规则：

- 目标 PTTL 比源短超过 `TTL_TOLERANCE_MS = 1000ms` → 拒绝；
- `source=-1` 时 `target` 必须也是 `-1`；
- `target=-1` 且源有限 → 视为安全；
- 目标已到期/即将到期 → 拒绝；
- 正常（目标 TTL 足够）仍删除。

测试覆盖：值相同但目标 TTL 短、source=-1/target 有限、target=-1/源有限、两个 run 中一个 TTL 不足时两个源都不删、delete 前目标被改/过期。

### I-3：故障/竞态/分页/契约测试
