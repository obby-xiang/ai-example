  --dir "$GITHUB_WORKSPACE/backend/target/e2e-artifacts/stub" \

- **常驻起法**＝ `nohup … &` + `$!` 写 pid 文件；收尾步 `if: always()` 用 `kill "$(cat backend/target/e2e-artifacts/stub.pid)"`。用**进程替换** `> >(tee -a …)` 而非 `node … | tee`，目的是让 `$!` 仍是 node 的 PID（管道形态下 `$!` 会是 tee 的 PID，kill 会杀错）。
- 启动前另有一道自检（仓库根执行）：`node scripts/ci/stub-upstream.mjs --self-check`。
- **参数表**：`--port`（默认 `18399`）、`--dir`（dump 目录，默认 `cwd/stub-dump`）、`--violate-form-type`（请求级缺陷注入，仅 GF6 用例触发；另有 `--violate-form-keys`）、可选 `--routes <stub-routes.json>`、`--self-check`。
