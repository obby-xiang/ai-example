## 一句话概括

这是一个 **「AI 辅助配置快速实施平台」的全栈演示/实战工程**：业务侧做「动态配置项」的定义、数据浏览、Excel 导入/导出/发布；AI 侧是一个自建的 **Agent Runtime**，让模型能在页面内通过对话驱动这些业务动作（调工具、渲染表单、高风险操作前挂起等人类确认）。

## 业务功能（后端 + Vue 前端）

- **配置定义管理**：动态字段（类型/必填/主键/引用）+ 层级（GLOBAL / REGION / PROJECT）
- **数据浏览**：用 GrapeCity **SpreadJS** 17 做表格展示与编辑
- **导出向导**：选定义 → 查条件 → 建导出作业 → 打包下载
- **导入向导**：下模板 → 上传匹配 → 预检查（必填/主键重复/引用存在）→ 导入 → 发布
- **任务中心 / 作业**：四类异步作业，带进度事件流、取消、僵尸作业恢复
- **发布语义**：范围替换（行级 upsert + 范围差集删除）+ 乐观锁冲突检测

## AI 部分才是重点（`backend/.../ai/` 16 个子包，259 个 Java 文件）

| 机制 | 做法 |
| --- | --- |
| 工具循环 | 用 Spring AI 官方 `ChatClient`，不自研循环 |
| 渐进式披露 | `@ToolScope` 按页面/任务只暴露当前可用工具 |
| 生成式表单 | `generative_form` 工具 + 前端 `FormRenderer`，对话内渲染结构化表单（六种字段类型白名单） |
| 人工确认门 HITL | `start_export/precheck/import/publish` 执行前挂起，出确认卡片，拒绝/超时按"未执行"回填 |
| 前端工具回灌 | 后端是哨兵桩，副作用在浏览器，结果经 `POST /api/ai/frontend-tool-result` 续跑 |
| 取消/续跑 | 取消接口、`lastSeq` 差量重连、启动后自动续跑 |
| 会话 | 记忆存 Redis（6h 滑动 TTL），同 sessionId 串行化（占用返回 409），SSE 自有帧契约带单调 `seq` |

前端除五个业务页外还有 **AiSettingsView**（模型/Provider 配置，支持 DB 托管密钥 + `AI_SECRET_KEK` 信封加密）和 **AiFeedbackView**。
