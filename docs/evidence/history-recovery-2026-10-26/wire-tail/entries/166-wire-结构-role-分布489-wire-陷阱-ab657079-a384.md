# 4. wire.jsonl 记录格式

JSONL，**每行一条独立事件对象，类型由顶层 `.type` 区分**。没有统一的 `.role` / `.content` 顶层字段——role 是**嵌套**的。

前几条固定序（每个 wire 都一样）：`metadata` → `runtime.set_binding` → `mcp.tools_discovered` → `profile.bind` → `permission.set_mode` → …

### 关键类型与字段路径

| 用途 | `.type` | 字段路径 |
|---|---|---|
| 文件头/创建时间 | `metadata` | `.protocol_version`（"1.5"）、`.created_at`（epoch **毫秒**） |
| workdir 绑定 | `runtime.set_binding` | `.workspaceId`（=`<WORKSPACE>`）、`.agentId`、`.time` |
| **模型身份（会话级）** | `profile.bind` | `.modelAlias`（如 `kimi-code/k3`）、`.thinkingEffort`、`.profileName`、`.systemPrompt` |
| **模型身份（每次请求）** | `llm.request` | `.model`（如 `k3`）、`.modelAlias`、`.provider`、`.messageCount`、`.turnStep` |
| 用量 | `usage.record` | `.model`、`.usage`、`.usageScope` |
| **真人用户输入** | `turn.prompt` | **`.origin.kind == "user"`**；文本 `.input[].text`、`.input[].type=="text"`；时间 `.time`（ms）；`.promptId`、`.turnId` |
| 后台任务通知（非真人） | `turn.prompt` | `.origin.kind == "task"`，`.origin.taskId/.status/.notificationId` |
| 子智能体收到的任务（非真人） | `turn.prompt` | `.origin.kind == "system_trigger"` |
| 用户消息（会话转录副本） | `agent.message.appended` | **`.message.message.role`**；文本 `.message.message.content[].text` |
| 上下文消息 | `context.append_message` | **`.message.role`**；文本 `.message.content[].text` |
| 助手/工具消息 | `agent.message.appended` | 同上，role = `assistant` / `tool` |
| 轮次 | `agent.turn.started` / `turn.ended` | `.turnId` |
| 子智能体生命周期 | `subagent.spawned` / `.started` / `.completed` | `.agentId` |

### role 的实际取值分布（全 489 个 wire 实测）

| 记录类型 | main wire | sub wire |
|---|---|---|
| `turn.prompt` origin.kind=`user` | **424** | 0 |
| `turn.prompt` origin.kind=`task` | 103（后台任务完成通知） | 2 |
| `turn.prompt` origin.kind=`system_trigger` | 0 | 464（父 agent 派发的任务） |
| `agent.message.appended` role=user | 682 | 765 |
| `agent.message.appended` role=assistant | 4354 | 20386 |
| `agent.message.appended` role=tool | 4886 | 26465 |
| `context.append_message` role=user | 1233 | 1503 |

### 重要陷阱

`role == "user"` **不等于真人输入**。同一 session 的 `main:user` 计数：`turn.prompt`=424，但 `agent.message.appended` role=user=682、`context.append_message` role=user=1233。多出来的部分是系统注入的 user 角色消息，实测样本包含：

- `<system-reminder> Today's date is ...` / `Auto permission mode is active ...`
- `<notification id="task:agent-xxx:completed" category="task" type="task.completed" ...>`（后台任务完成）
- `<system-reminder> <plugin_session_start plugin="superpowers" ...>` / `<tools_added>`
- 有时 harness 会把 `<git-context>` 块**拼进真人消息文本**（不是独立记录）

因此：**要"只提取真人用户消息"，唯一干净的口径是 `type=="turn.prompt" && .origin.kind=="user"`**（且只在 main wire 上过滤，因为 sub wire 里这一 kind 恒为 0）。`origin.kind=="task"` 是后台任务通知，也要排除。

另：`.origin.clientMetadata` 里带的是编辑器 composer 富文本 doc，实测无凭据。

# 5. 建议的提取方法

本机 **没有 jq**（`which jq` → not found），Python 3.14.8 可用，所以走 Python。以下命令已实测跑通（只读）。

**A. 单文件：抽取某 session 的真人用户消息**

```bash
python -c "
import json
f=r'<KIMI_SESSIONS>
for l in open(f,encoding='utf-8'):
    o=json.loads(l)
    if o.get('type')=='turn.prompt' and o.get('origin',{}).get('kind')=='user':
        print(o['time'], '|', '\n'.join(p['text'] for p in o['input'] if p.get('type')=='text'))
"
```

**B. 全库：把 81 个 main wire 的真人消息汇总（带 session/时间）**

```bash
python - <<'PY'
import json, glob, os
base = r'<KIMI_SESSIONS>'
for w in sorted(glob.glob(base + '/*/agents/main/wire.jsonl')):
    sid = w.replace('\\', '/').split('/')[-4]
    for l in open(w, encoding='utf-8'):
        if '"turn.prompt"' not in l:
            continue
        o = json.loads(l)
        if o.get('type') != 'turn.prompt' or o.get('origin', {}).get('kind') != 'user':
            continue
        txt = '\n'.join(p.get('text', '') for p in o.get('input', []) if p.get('type') == 'text')
        print(f"{sid}\t{o.get('time')}\t{txt[:200].replace(chr(10),' ')}")
PY
```

**C. 若想要「含通知在内的一切 user 角色记录」**（通常不是你要的，仅备查），把过滤条件换成：

```python
# agent.message.appended 转录口径
o.get('type')=='agent.message.appended' and o['message']['message'].get('role')=='user'
#   → 文本: o['message']['message']['content'][i]['text']   （需自行剔除 <system-reminder> / <notification>）
```

**D. 子智能体侧**：把路径换成 `*/agents/agent-*/wire.jsonl`，过滤条件换成 `.origin.kind == "system_trigger"`（`turn.prompt` 仍可用，字段路径完全相同）。
