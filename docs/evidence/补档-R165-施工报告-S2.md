## 4. 蓝本（v7.html）偏离与裁决清单

| # | 项 | 蓝本 | 本仓落地 | 理由 |
|---|---|---|---|---|
| R1 | 所有描边 | 依赖 preflight 全局 `border-style:solid` | 逐条显式 `border-solid` | **S1 §5① 教训前置**：本仓 `corePlugins.preflight=false`，纯 `border-*` 只出 width、style 恒 none ⇒ 环/行线/卡片全不显 |
| R2 | 门卡字段表行数据 | `任务名/操作/影响面`（demo 写死） | 「操作」=工具中文名 + args 前 4 键（`gateRows`） | 本仓无 影响面 字段；args 即"将要执行什么"的真相，不外推 |
| R3 | 用户气泡字号 | `.ucard{font-size:13.5px}` | **按 role 分派**字号类 | 原实现 `text-[13.8px]`(base) 与 `text-[13.5px]`(user) 同特异度并存 ⇒ 与 S1 §5② 同源风险；改成互斥分派后零顺序依赖（实机 13.5/13.8 双值正确） |
| R4 | 回执卡 `原始参数` | 裸 `<pre>`（长文不折叠） | v7 kv/pre 形制 **+ 保留 CollapsibleText** | 指令要求"按 v7 结构替换用法"；组件是既有能力（真溢出渐隐/显示更多），删掉会退化长参数体验 ⇒ 结构照 v7、能力保留 |
| R5 | 骨架屏动画 | `animate-shimmer`（demo 临时 config 私有） | 内置 `animate-pulse` | 仓库 `tailwind.config.js` **禁改**、仓库 CSS 无 shimmer keyframes；同语义的无限占位律动（与 S1「`animate-spin7`→`animate-spin`」同款处置） |
| R6 | 元信息行 margin | `.afoot{margin:6px 0 18px}` 为**整个 turn 的末行** | 照抄 6px/18px，但本仓该行在消息行（`mb-3.5`=14px）内 ⇒ 实测两条消息间距 **32px**（v7 约 18px） | 字面照做；若要 v7 间距需同时撤消息行 `mb-3.5`（属布局面改动，未擅动）——**待裁** |
