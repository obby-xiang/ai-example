# 决策卡-R161-定稿（AI 面板滚动行为专项）

- 立项：R-161（占 R 空号；R-156~R-160 已占/拟占）｜来源：用户直报两缺陷｜日期 2026-10-13
- 会审：DS V4 Pro 单方评议（会话 `f0e62484`）= **有条件通过（MAJOR 0 / MINOR 6）**，6 条已全部并入本定稿；报告 `r161-scroll/会审报告-R161-DSPro.md`。
- **事实源 = 用户确认 demo** `r161-scroll/demo-scroll.html`（验证 9/9 PASS + 阈值业界口径复验，`demo-验证报告.md`）；根因 `滚动根因排查.md`（agent-845）；业界调研 `业界滚动调研.md`（agent-846）。
- 问题：①回复中出现 tool part（确认门/生成式表单/工具卡）不自动钉底（文本 delta 会滚）；②上滚一点（≥32px）即出「回到底部」浮钮。
- 根因（实证，会审四锚全准）：
  - **RC-1** 指纹 watch 只取末段（`AiPanel.vue:1041-1047`），`upsertToolPart` 就地 splice 不进指纹（`parts.ts:90-103`）；
  - **RC-2** `scrollBottom` 单次 nextTick 快照（`:741-752`），消息容器无 ResizeObserver，后增高度无人重钉（`:1052` setTimeout hack 旁证）；
  - **RC-3** 32px 闸误锁（`:496` 唯一置 false 点）——含**程序化滚动回声误置**子型（demo 打点实证：程序钉底后异步 scroll 事件读中间态 d=42 误置 followBottom=false）；
  - **②** `BOTTOM_THRESHOLD_PX=32`（`:489`）一值双用（跟随闸 `:496` + 出钮判据 `:499→:392`）。

## 一、方案（demo 定稿口径 + 会审并入）

1. **RO 内容重钉底**：`msgWrapRef` 挂 ResizeObserver，内容增高且 followBottom=true ⇒ `pinBottom()`；onBeforeUnmount disconnect（照 `:1081-1084` 纪律）；覆盖 RC-1/2，`:1052` setTimeout hack 撤除。**指纹 watch 保留**（会审 M5 裁决：RO 接管后冗余但幂等无害，移除属额外面，不动）。
2. **程序化滚动回声闸**（覆盖 RC-3 全型）：一切钉底走统一 `pinBottom()`（设 scrollTop + 记落点 + 置 followBottom=true）；onScroll 判回声 = `|scrollTop − 落点| ≤ 1px`（会审 M1：容差判据，非精确等于）只刷读数不动闸；收口前须以 demo `_trace` 法复验 overflow-anchor 场景留证。
3. **阈值拆分**（修②；出钮阈值**用户直裁 = 业界主流滞回口径**）：`FOLLOW_THRESHOLD_PX=32` 保留；浮钮 = **离底 >64px 显示、<24px 隐藏**（滞回；常量化、与 clientHeight 无关）。
4. **平滑回底**（用户直裁=做）：走 **CSS `scroll-behavior:smooth` 类切换**（demo 已验证形态），**禁 `scrollTo({behavior:'smooth'})`**（会审 M2：jsdom 不同步更新 scrollTop，保 `:600-620`/`:801-826` 同步断言）；用户滚动可打断；**backToBottom 须显式置 showBackToBottom=false**（会审 M3：滞回态非纯计算，否则「点击后钮消失」断言不成立）；到底置 followBottom=true。
5. **role="log"** 补滚动容器（`:118`，无视觉影响）。

## 二、范围外（明确不做）

- 速度感知脱离（use-stick-to-bottom 式）——挂账可选。
- CollapsibleText 内部 RO 兜底（issue #14 批面）。

- 门禁：前端 265 基线+新增例全绿、typecheck 0、build ✓；后端零动；check-docs 6/6；ls-files 1103 起算。

## 四、风险
