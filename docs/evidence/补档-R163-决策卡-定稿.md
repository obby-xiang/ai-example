# 决策卡-R163-定稿 · AI 对话体验专项（草案 K3 草拟 2026-10-14，经 DSPro 评议闭合，2026-10-14 定稿）

## 一、背景（实机核验结论，截图 r163-audit/）
AiPanel 现状与业界差距实见确认：①Markdown 零渲染（**/表格/代码围栏原样可见，AiPanel.vue:193 纯插值+whitespace-pre-wrap）；②工具卡折叠态仅 图标+名+2tag 无摘要，展开抛裸 JSON 带字面 \n；③GF 回执=10 行 JSON 墙；④text 段零间距连成一片；⑤400px 栏内 13px+max-w-82% 致 JSON 每 8-10 字折行；⑥同屏 7-8 种颜色靠色撑层级；⑦「回到底部」浮标遮正文。用户直裁「巨丑无比」，启动本专项。

## 二、范围（用户逐项裁决，demo v6=视觉基准 http://localhost:18330/ 存档 r163-demo/）
### 纳入（7 项）
1. **Markdown 流式渲染**：合规四件套锁定版本 markdown-it@15.0.0 + dompurify@3.4.14 + highlight.js@11.11.1 + mermaid@11.16.1（公司清单核准；shiki/markstream-vue/markdown-it-task-lists 不合规排除）。
2. **工具卡改造**：折叠态=状态图标+工具名+一行自然语言摘要（前端映射生成，禁模型写文案）+9 态真实卡片（等待确认/调用中/已成功/执行失败/已拒绝/超出当前范围/会话已失效/已取消/结局未知）；展开体 input/output 格式化 JSON+长结果「已截断」角标；裸 JSON 墙消除。
3. **排版基线**：段间距/列表缩进/字号行高（13.5-14px/1.7）/色彩收敛（中性灰+品牌蓝+语义色仅状态）/浮标不遮正文。
4. **消息框架**：去头像（双侧）；用户消息=内容-only 卡片+下行 时间靠右+图标操作（编辑/复制）；助手回复=无气泡全宽+下行 时间靠左+图标操作（复制/赞/踩——赞踩图标/本地态/选中互斥可取消均由本项交付，前端无既有赞踩代码可复用，见本卡第 7 项与 M2 闭合）；操作行统一 hover 浮现（各行 hover 行为一致）、28×28 热区 gap≥8、点击气泡提示不挤布局不丢按钮；流式期=呼吸「● 工作中…」（reduced-motion 豁免，R-161 立法延续），完成换时间戳行；严格按 parts 时序交错渲染（数据层已保序，见 §三.5 锚点订正）；正文不截断（折叠仅留思考块/工具 output，CollapsibleText 退出正文链路）。
5. **编辑**=内容复制回输入框；输入框非空白（非全空白字符）时先弹确认防覆盖。
6. **「继续」按钮**：error/断流/取消后消息级入口，点击=把「继续」当作用户消息直接发送（参考 Kimi）。
7. **赞踩上报闭环**：前提订正=前端无赞踩代码，demo 中的赞踩仅为静态示意；本项=**纯后端 + 查看界面**（上报端点+落库+设置页查看界面）；前端图标/本地态/互斥归第 4 项交付并交叉引用。闭环四要素见 §三.4。
### 暂缓（挂账，另立项再议）
分叉轮播 ‹2/3›、重新生成保留旧版、sources 引用标注、/命令、附件/语音、token 用量、模型切换、消息搜索、TTS、快捷键（Esc/↑）、分享/导出、深色模式、KaTeX 公式。
### 明确不做
多会话管理（列表/重命名/搜索）。

## 三、技术要点
1. **渲染层重做**：AiPanel.vue:193 按 role 分流；markdown-it→DOMPurify→v-html 为唯一正文链路；chSplit/CH_TAIL 逐字符 span（:787-798）退役；showCaret(:925) 保留至流式结束。**语义声明**：R-159「新字符逐字符渐显」语义被 Markdown 渲染取代（非静默丢弃），R-159 相关 spec 口径同步改写。死 testid 清理：chSplit 退役后 `stream-caret`/`span.ch` 等无消费方的 testid 一并删除。
2. **流式策略**（markdown-it 非增量解析器，全量重解析=O(n²)）：30-60ms 节流批量重渲染；**只重渲未闭合尾部块**，已完成块 DOM 冻结/块级 memo 不重解析；未闭合代码围栏降级纯文本、闭合后二次高亮；勿每 token 全量同步高亮；长文（>10k char）降级阈值与单次重渲染耗时预算须在施工卡写明并实测。
3. **XSS 口径重定义（含白名单实际集合）**：全仓「永不 v-html」改为「AI 正文链路仅允许 markdown-it 产出经 DOMPurify 白名单净化后 v-html」。
   - 白名单标签：p/h1-6/ul/ol/li/table/thead/tbody/tr/th/td/code/pre/blockquote/em/strong/del/a/hr/br + span.class="hljs-*" + code.class="language-*" + mermaid svg 族。
   - 白名单属性：仅 a.href（走 DOMPurify 默认协议过滤）+ class + img.src/alt。
   - 明确禁止：style/on*/iframe/script/表单控件（task-lists 已排除，input[checkbox] 不进白名单）。
   - **安全口径变更须单列签核**：松弛面仅限「AiPanel 正文链路 = markdown-it → DOMPurify → v-html」；FormRenderer（frontend/src/components/AiPanel/FormRenderer.vue:12）永不 v-html 不变，本专项不触碰该文件的字段文案安全边界（草案原引 :12,111 路径/行号偏差，以本节为准）。
4. **持久化不动 + 赞踩 net-new（分列）**：Redis 6h 滑动 TTL + 镜像恢复维持现状；DB parts[] 不变，DB parts[] 升级为 R-163d 挂账缓议；**赞踩落库为净新增持久化面，与 parts[] 不冲突**。赞踩闭环四要素：
   ①API：POST /api/ai/feedback，请求体 {messageId,sessionId,rating∈1/-1/0,reason?}，幂等 upsert（rating=0=取消），租户/用户隔离。
   ②落库 schema：新表 ai_feedback（message_id 唯一）net-new，不动 parts 持久化。
   ③查看界面：设置页「AI 反馈」列表（时间/消息摘要/rating/reason），仅当前用户可见。
   ④消费方：人工复盘，无自动回流。
5. **回归面（锚点订正）**：tests/ai-panel-parts-render.spec.ts 7 处 stream-caret + 2 处 whitespace-pre-wrap 断言须改写（共 9 处，改后须保绿）。锚点订正：parts.ts:29,44 是 nextSeg/openStreamPart，**不是**保序锚；保序是 parts 数组顺序 + seg 单调的隐含性质。计数口径分列：291/291·21 spec 系 R-162 现状口径，与本批改写后的目标计数须分开表述（目标见 §五.2）。门禁 前端 291/291·21 spec、check-docs 6/6、后端 496/496 须保绿。
6. **工具卡摘要映射表**：工具名→中文动宾模板（如 str_replace_editor→「已编辑 N 个文件 +A −R」），失败/未知工具兜底=工具名+状态。施工卡首任务=枚举前端工具全集（如 web_search / str_replace_editor / …）并输出**逐工具摘要映射表**，禁止施工时凭猜。
7. **mermaid 渲染与安全**：触发条件=围栏未闭合前保持源码块，围栏闭合后一次性渲染（流式期 mermaid 不可增量）；失败判定（render error）须在施工卡明确阈值；配置 securityLevel:'strict' + htmlLabels:false + suppressErrorRendering:true，输出 SVG 再过 DOMPurify（SVG profile）；施工前置项=核 mermaid@11.16.1 对 dompurify@3.4.14 的 peer 版本兼容（须确认 11.x 接受 3.x）。
