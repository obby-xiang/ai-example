## 6. 取数命令（可机械重算）

在仓库根目录执行（`docs/evidence/baseline-combined.md` 为唯一事实源）：

```sh
# ① 主表数据行数（分母；期望 50）
grep -c '^| B[1-4]\.[0-9]' docs/evidence/baseline-combined.md

# ② 残留占位（期望 0 / 0）
grep -c '待重放' docs/evidence/baseline-combined.md
grep -c '待比对' docs/evidence/baseline-combined.md

# ③ 分类点数（期望 7 / 39 / 2）
grep -c '一致（显式指名）' docs/evidence/baseline-combined.md
grep -c '一致（引用式' docs/evidence/baseline-combined.md
grep -c '一致（有意差异）' docs/evidence/baseline-combined.md

# ④ 未对照行数（只数数据行的双列成对；期望 4）
grep -c '未对照（无独立证据） | 未对照（无独立证据） |' docs/evidence/baseline-combined.md

# ⑤ 反算
#   一致行 = ③的显式指名 7 + 引用式 39 = 46
#   口径 A：46 / 50 = 92.0%
#   口径 B：46 / (50 − ④的 4) = 46 / 46 = 100.0%
```

> 注：`grep -o '未对照（无独立证据）' … | wc -l` 会**多算 1 处**（`baseline-combined.md` 头部指针注记正文里也出现了该词），故 ④ 采用"双列成对"模式只数数据行。
