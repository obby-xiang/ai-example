## 0. 一句话结论

**不是"样式没移植好"，是"移植对象选错了"。** demo 是「语义类 + 全局样式表」两件套；真实前端是「Tailwind 原子类 + Element Plus 组件」两件套。R-163→B→C→D 四轮都在往 ai-chat.css 里补样式，但真实 DOM 从未改用 demo 类名（全仓 ucard/umsg/uft/acts/icon-btn/tcard/ti/tname/tsum/tact/stchip/chip-*/reason-hd/rh-ic/rname/rsum/grows/grow/gk/gv/ring/gf-hd/fld/fi/fmsg/rc-badge/rc-row/rc-toggle/rc-detail/rc-kv/ctxbar/hdot/notice/enotice/longtext/decnote/stopbtn/fabtip 出现次数全部为 0）。因此 ai-chat.css 只对「正文 v-html」（markdown.ts 自产 demo 类名）与 3 个手写块生效，demo 的整卡体系、按钮体系、胶囊体系、表单体系与 DOM 零交集——四轮修补全部落在空处。
