# 测试用例

- 项目：ai-example-deepseek-v4-pro
- 自动化脚本：`scripts/verify-e2e.ps1`（19 个测试组，后端运行时执行）
- 验证结果记录：docs/05-验证结果.md

## 一、测试策略

| 层级 | 方式 | 覆盖 |
|---|---|---|
| 单元 | 规则引擎/拓扑排序/文件名匹配 经 E2E 场景间接全覆盖 | 校验规则、依赖顺序 |
| 接口 | PowerShell 脚本直连 REST API | 全部后端接口 |
| 集成 | 真实文件（xlsx/zip）经 API 上传解析 | POI 与 SpreadJS 格式互通（xlsx 规范） |
| E2E | AI 对话真实调用 DeepSeek（流式/工具/HITL） | 后端 AI Runtime |
| 界面 | 浏览器人工核查（向导/SpreadJS/AI 面板） | 前端交互 |
