# 需求规格说明书 — 配置快速实施平台（AI 辅助）

版本：v1.0　日期：2026-10-05

## 1. 背景与目标

企业系统中存在大量"配置项"（如国家字典、税率、项目类型等），每种配置项结构不同且需要动态定义。实施过程中需要批量导出、导入配置数据。本平台提供：

1. **动态配置项管理**：配置项结构（字段、类型、必填、枚举选项、跨配置项引用）由元数据驱动，动态渲染。
2. **快速实施任务向导**：导出配置（选择→查询→导出）、导入配置（上传→检查→导入→发布）两类多步骤任务，支持更多任务类型扩展。
3. **任务管理**：任务持久化，可查看历史任务的状态与进度。
4. **AI 对话辅助**：右侧常驻 AI 对话栏，理解当前页面/任务上下文，可调用工具直接操作用户界面与后端数据。

## 2. 领域模型

### 2.1 配置项定义（ConfigDefinition）
| 属性 | 说明 |
|---|---|
| code | 配置项编码，唯一，如 `COUNTRY` |
| name | 中文名称 |
| level | 层级：GLOBAL（全局）/ REGION（地区）/ PROJECT（项目），一个配置项只属于一个层级 |
| description | 描述 |
| fields | 字段定义数组：`{name, label, type, required, options?, maxLength?, ref?}` |
| dependsOn | 依赖的其他配置项编码列表（导入/检查/发布按拓扑序处理） |

字段类型：`STRING` / `NUMBER` / `DATE`(yyyy-MM-dd) / `ENUM`(options 下拉) / `BOOLEAN`。
`ref: {def: 配置项编码, field: 字段名}` 表示该字段取值必须存在于目标配置项的目标字段中（跨配置项引用完整性）。

### 2.2 配置数据（ConfigData）
已发布的业务数据行：`{defCode, rowNo, data: {字段名: 值}}`。发布语义为**按配置项全量替换**。

### 2.3 暂存数据（StagingConfigData）
导入任务专用的未发布数据：`{taskId, defCode, rowNo, data}`。导入写入暂存区，发布时校验并合并到正式区。

### 2.4 任务（Task）
| 属性 | 说明 |
|---|---|
| taskNo | 任务编号，如 `EXP-20261005-0001` |
| type | EXPORT / IMPORT（可扩展） |
| name | 任务名称 |
| status | DRAFT / IN_PROGRESS / COMPLETED / FAILED / CANCELLED |
| currentStep | 向导当前步骤 |
| stepData | 向导数据（已选配置项、查询条件等），JSON |
| progress | 0-100 |

选择任务类型创建任务时即持久化。

### 2.5 作业（JobRun / JobItem）
长耗时操作（导出/检查/导入/发布）统一抽象为后台作业：
- JobRun：`{taskId, kind: EXPORT|CHECK|IMPORT|PUBLISH, status, total, processed, currentItem, result, error, 起止时间}`
- JobItem：`{jobId, defCode, seq(拓扑序), status, totalRows, okRows, errorRows, message, detail(逐行错误，截断)}`
- 前端轮询作业进度（1s），展示整体进度条 + 每个配置项的明细状态。

## 3. 功能需求

### FR-1 配置项元数据
- 系统预置 ≥6 个示例配置项（覆盖三种层级、各种字段类型、ref 引用、依赖关系），启动时播种。
- 提供配置项列表、详情、数据查询（按字段条件：EQ/NE/LIKE/GT/GE/LT/LE/BETWEEN/IN）API。

### FR-2 导出配置向导（3 步）
1. **选择配置**：配置项多选（按层级筛选、搜索）。
2. **查询配置**：按每个配置项的字段结构动态生成查询条件表单；可预览命中行数。
3. **导出配置**：后台作业按条件查询并生成结果；页面显示进度；每个配置项的数据用 SpreadJS 在线展示/编辑；支持单个配置项下载 xlsx、任选多个打包 zip、全部打包 zip。编辑只影响下载文件，不回写数据库。

### FR-3 导入配置向导（4 步）
1. **上传配置**：选择配置项（多选）；可下载模板（单个 xlsx / 多个 zip，含表头与下拉校验）；可上传 xlsx（单文件）或 zip（多文件），**按文件名中的配置项编码匹配**到对应配置项；未上传的配置项也可基于模板在 SpreadJS 中在线编辑；上传后覆盖对应编辑区。
2. **检查配置**：后端预检查作业（必填、类型、枚举、ref 引用完整性、依赖拓扑序），显示进度与逐配置项/逐行检查结果。
3. **导入配置**：后端导入作业，再次校验后写入暂存区（未发布），显示进度与结果；依赖失败的配置项其后置依赖项跳过。
4. **发布配置**：用户核查暂存数据后发布；发布作业再次校验后将暂存数据全量替换到正式区，显示进度与结果；成功后任务完成。

### FR-4 任务管理
- 任务列表页：编号、名称、类型、状态、进度、当前步骤、创建/更新时间；支持打开继续、取消、删除。
- 创建任务（选择类型）即持久化。

### FR-5 AI 对话栏
- 右侧常驻，左右双栏布局；界面全中文。
- 会话以浏览器页签为单位（sessionStorage 存 sessionId），刷新可恢复，不需要持久化历史。
- AI 能感知当前页面/任务/步骤/已选配置项（请求时上下文注入）。
- AI 通过工具调用完成动作：查询配置元数据/数据量、任务增查、页面导航、代选配置项、代填查询条件、下载模板/导出文件、启动导出/检查/导入/发布（破坏性动作需用户在对话中确认）。
- AI 回复流式输出（SSE）。
- 不同页面/步骤提供不同工具（渐进式披露），AI 不可越权调用当前页面不可用的工具。

## 4. 非功能需求
- 后端 Spring Boot 3.5.14 + JDK 21 + Spring AI 1.1.8（OpenAI 兼容协议对接 DeepSeek）；Maven 构建。
- 前端 Vue 3 + Vite + GrapeCity SpreadJS 17.1.5 + Element Plus；Yarn 管理。
- 数据库 H2（文件模式，嵌入式）；不使用 Redis（会话态为单机内存，任务态在 DB）。
- AI 运行时在后端：API Key 不下发前端。
- 长作业异步执行、可取消、进度可查；接口幂等（重复提交不重复创建作业）。
- 并发假设：单机单用户演示规模，不做多用户权限体系。
