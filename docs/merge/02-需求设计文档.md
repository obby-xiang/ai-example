# 需求设计文档 —— AI 辅助配置快速实施平台（生产落地版）

> 文档编号：RD-001　版本：v2.0（落地版）　日期：2026-10-05
> 编制依据：对 ai-example 仓库 6 个 demo 分支的评审结论（见《01-分支评价报告》），在其功能长板基础上补齐真实业务落地所必需的需求项。
> 与 demo 的差异标记：【新增】= 各 demo 分支均未覆盖、为真实业务落地新增的需求；【强化】= demo 已有雏形、按生产标准强化的需求。

---

## 1. 背景与目标

### 1.1 业务背景

企业在实施/运维过程中存在大量**动态配置数据**（参数字典、阈值规则、地区/项目级业务配置等），具有以下特征：结构随业务演进频繁变化、按"全局/地区/项目"分层生效、配置间存在依赖与引用关系、变更需要受控（校验→暂存→审批→发布→可追溯）。传统方式是实施人员手工维护 Excel 再导入系统，效率低、易出错、不可追溯。

### 1.2 建设目标

1. **配置即元数据**：配置项结构（字段/类型/校验/层级/依赖/引用）完全由元数据驱动，新增配置项零代码上线。
2. **实施任务化**：导出/导入/变更全程以"任务"为载体，状态可查、进度可见、异常可恢复、结果可追溯。
3. **AI 辅助实施**：常驻 AI 助手理解当前工作区上下文，可代为导航、选配置、填条件、发起任务；破坏性操作必须经人确认（HITL），AI 行为全程可审计。
4. **生产可用**：具备认证授权、数据权限、审计、版本回溯、高可用与可观测能力，满足企业合规要求。

### 1.3 范围

- 本期包含：配置定义管理、配置数据浏览、导出配置任务、导入配置任务（检查/暂存/发布）、任务中心、AI 对话助手、认证授权与审计、版本管理。
- 本期不包含：配置运行时下发到业务系统的通道（由下游系统自行拉取/API 查询）、工作流引擎级多级审批（本期为单级审批，接口预留）。

## 2. 角色与权限【新增】

| 角色 | 职责 | 关键权限 |
|---|---|---|
| 实施工程师 | 日常导出/导入/编辑配置 | 任务创建与执行、AI 使用、本人数据权限范围内的配置读写 |
| 实施主管 | 发布审批 | 发布审批通过/驳回、查看全部任务 |
| 配置管理员 | 元数据管理 | 配置定义的新增/修改/停用、种子/字典维护 |
| 审计员 | 合规审计 | 只读访问审计日志、操作流水、版本快照 |
| 系统管理员 | 平台运维 | 用户/角色/权限管理、AI 模型与配额配置 |

权限模型：RBAC + **数据权限**（地区/项目维度，用户仅能操作其授权范围内的配置数据；AI 工具调用继承同一权限上下文，不得越权）。

## 3. 领域模型

| 实体 | 说明 | 关键属性 |
|---|---|---|
| ConfigDefinition 配置定义 | 配置项元数据 | 编码、名称、层级（GLOBAL/REGION/PROJECT）、字段集、依赖（dependsOn DAG）、状态（启用/停用）、版本 |
| ConfigField 字段定义 | 配置项的字段 | 编码、类型（文本/长文本/数字/布尔/日期/枚举/引用）、必填、枚举选项、引用目标（defCode.field）、是否业务键 |
| ConfigData 配置数据 | 已发布生效数据 | 定义编码、范围（地区/项目）、行数据（JSON）、版本号、状态（PUBLISHED）、生效时间 |
| StagingData 暂存数据 | 导入未发布的草稿 | 按任务隔离，发布后清除 |
| ConfigVersion 配置版本【新增】 | 每次发布的快照 | 版本号、 diff 摘要、发布人、审批人、发布时间、回滚指针 |
| Task 任务 | 一次导出/导入实施过程 | 任务号、类型、状态机、当前步骤、参数（选择集/条件）、创建人 |
| Job / JobItem 作业 | 任务内的异步执行单元 | 类型（EXPORT/PRECHECK/IMPORT/PUBLISH）、状态、进度、逐项明细、行级校验问题 |
| AiSession AI 会话 | 页签级 AI 对话 | 会话 ID、页签绑定、消息历史、待确认交互、TTL |
| AuditLog 审计日志【新增】 | 全量操作流水 | 操作人、动作、对象、前后值摘要、来源（界面/AI）、IP、时间 |
| Approval 审批单【新增】 | 发布审批 | 任务/批次、申请人、审批人、结论、意见 |

## 4. 功能需求

### FR-1 配置定义管理

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-1.1 | 配置定义的查询/详情：含字段结构、依赖关系、已发布数据行数 | P0 |
| FR-1.2 | 字段类型不少于 7 种：文本、长文本、数字、布尔、日期、枚举（下拉）、引用（指向其他配置项字段）；支持必填与业务键标记 | P0 |
| FR-1.3 | 层级三级：GLOBAL（全局唯一）、REGION（按地区）、PROJECT（按项目）；范围维度参与业务键唯一性 | P0 |
| FR-1.4 | 配置定义的可视化编辑（新增字段/修改属性/停用），修改即时影响动态渲染，变更记录审计 | P1【强化】 |
| FR-1.5 | 依赖关系定义与 DAG 校验：禁止循环依赖；依赖图可视化展示 | P1 |

### FR-2 导出配置任务

向导步骤：选择配置（多选）→ 动态查询条件 → 执行导出 → 结果下载。

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-2.1 | 配置多选；选择时自动拓扑排序提示依赖项（未选中的依赖项导出正式区数据为准） | P0 |
| FR-2.2 | 按所选配置的字段动态生成查询条件表单（类型感知：枚举下拉、日期选择器等）；支持字段级条件（EQ/NE/LIKE/IN/范围） | P0 |
| FR-2.3 | 异步导出：实时进度（SSE）、逐配置项明细、可取消；导出结果支持在线编辑（SpreadJS）、单文件下载、勾选打包、全部打包（ZIP） | P0 |
| FR-2.4 | 导出数据脱敏【新增】：标记为敏感的字段按角色脱敏（如部分掩码），脱敏规则可配置 | P1 |
| FR-2.5 | 导出量大时的分片与限流保护【新增】：单任务行数上限可配，超限需审批 | P2 |

### FR-3 导入配置任务

向导步骤：选择配置 → 准备数据（模板下载/文件上传/在线编辑）→ 检查 → 导入（暂存）→ 提交审批 → 发布。

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-3.1 | 模板下载：按配置定义生成 xlsx（表头含必填标记、枚举列内嵌数据验证下拉、引用列附说明）；多配置打包 ZIP | P0 |
| FR-3.2 | 文件上传：支持 xlsx 单文件与 ZIP 批量；按文件名匹配配置编码（支持序号后缀）；同名覆盖策略可选 | P0 |
| FR-3.3 | 检查（预检）：8 类规则——必填、类型、枚举域、引用完整性、业务键重复、依赖拓扑、范围有效性、自定义表达式；输出行级明细（行号/字段/原因）且可下载 | P0 |
| FR-3.4 | 导入：写入暂存区（按任务隔离），不影响生效数据；暂存数据可预览、可再次编辑 | P0 |
| FR-3.5 | 发布：**范围内替换**语义——仅替换本次导入涉及配置项 × 涉及范围的已发布数据，事务内完成；发布前终检；冲突检测（基于版本号乐观锁，他人已变更则提示） | P0【强化】 |
| FR-3.6 | 发布审批【新增】：发布前生成审批单，主管通过后执行；驳回则任务退回暂存态 | P0 |
| FR-3.7 | 版本快照与回滚【新增】：每次发布生成 ConfigVersion 快照与 diff 摘要；支持按版本回滚（回滚本身也走审批） | P1 |
| FR-3.8 | 导入模式：范围内替换（默认）/ 追加合并（按业务键 upsert） | P1 |

### FR-4 任务中心

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-4.1 | 统一任务列表：创建即入库；类型/状态/进度/操作人/时间展示；类型与状态过滤；服务端分页 | P0 |
| FR-4.2 | 任务恢复：运行中任务进度实时刷新；中断任务一键跳转向导对应步骤恢复并续订进度 | P0 |
| FR-4.3 | 作业治理【强化】：僵尸作业（服务重启残留 RUNNING）自动检测标记/恢复；取消真正生效（执行线程检查点响应） | P0 |
| FR-4.4 | 任务删除：级联清理作业、暂存、导出结果；删除动作入审计 | P1 |

### FR-5 AI 对话助手

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-5.1 | 常驻右侧对话栏：流式输出（思考链可折叠）、工具调用卡片可见、消息历史持久化（刷新/后端重启不丢；页签级会话隔离，新页签=新会话） | P0 |
| FR-5.2 | 渐进式工具披露：按当前页面/步骤/任务类型仅暴露适用工具子集（三重防线：工具过滤 + 系统提示词声明 + 执行兜底校验） | P0 |
| FR-5.3 | HITL 确认门：破坏性工具（启动导出/检查/导入/发布、删除任务）执行前渲染确认卡片；用户批准/拒绝结果如实回填模型；遗留未确认交互超时自动按取消处理 | P0 |
| FR-5.4 | 上下文感知与双向联动：请求时注入工作区快照摘要（页面/步骤/任务/选择集/数据版本）；AI 操作经契约层走与人工操作同一服务层与同一状态源；界面实时同步 AI 动作 | P0 |
| FR-5.5 | AI 权限约束【新增】：AI 工具调用强制携带操作人身份与数据权限上下文；AI 发起的发布必须走审批，不得绕过 | P0 |
| FR-5.6 | AI 可观测【新增】：每次对话记录 token 用量、工具调用序列、耗时；敏感配置数据进模型前脱敏 | P1 |
| FR-5.7 | 韧性：上游断流自动重试（有界）、确认门等待期间心跳保活、取消即时生效 | P0【强化】 |

### FR-6 审计与报表【新增】

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-6.1 | 全量操作审计：界面与 AI 通路同源记录（操作人/对象/前后值/来源/IP）；支持按人/对象/时间检索与导出 | P0 |
| FR-6.2 | 发布台账：版本快照、审批记录、回滚记录可查询 | P1 |
| FR-6.3 | AI 使用报表：会话量、工具调用分布、token 成本分部门统计 | P2 |

## 5. 非功能需求

| 类别 | 需求 | 指标 |
|---|---|---|
| 性能 | 常规操作响应；大数据量作业 | 查询类 API P95 ≤ 500ms；万行级导入检查 ≤ 60s；导出 5 万行 ≤ 90s |
| 并发 | 多用户并行实施 | 50 并发用户；同配置项发布串行化（乐观锁冲突率可见） |
| 可用性 | 服务重启不丢业务状态 | 任务/会话/进度持久化；重启后僵尸作业自动恢复；RTO ≤ 10min |
| 安全 | 认证授权、密钥管理、传输加密 | OAuth2/OIDC 登录；API Key 仅服务端环境变量注入；HTTPS；敏感字段加密存储 |
| 可观测 | 指标/日志/链路 | 作业成功率、AI 延迟与成本指标入库；关键链路 TraceID 贯通 |
| 兼容性 | 浏览器与文件格式 | Chrome/Edge 最近两版；xlsx（Excel 2016+ 兼容） |
| 可维护 | 元数据驱动扩展 | 新增配置项零代码；新增 AI 工具仅注解声明 |

## 6. 验收标准（摘要）

1. 导出/导入/发布全链路可走通且全程留痕（任务、审批、版本、审计四位一体）。
2. 发布语义正确性：多范围并存时范围内替换互不误伤；并发发布冲突被检测并提示。
3. 权限有效性：越权访问（含 AI 通路）100% 被拒绝并审计。
4. 故障恢复：导出/导入执行中重启服务，恢复后任务状态正确、可续看进度。
5. AI 全链路：渐进披露生效（越权工具不出现）、HITL 确认/拒绝行为正确、会话刷新与重启不丢、token 与工具调用可审计。
6. 自动化测试套件全部通过（详见《04-测试用例文档》），核心链路 E2E 可一键重复执行。
